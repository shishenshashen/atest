# 经纪商差异（点差/手续费）

> 同一个 EA 在不同经纪商表现**可以差 50%**。原因就是这些差异。
>
> **本 wiki 内容来源**: [[04-避坑与速查/04 经纪商差异-点差-手续费]] (v1.0, 15,163B, 339L, 11 反模式) + [[01-调用模块/M17 新闻过滤 NewsFilter]] 7 章节 spec + [[01-调用模块/M02 风控 Risk]] 7 项风控 + [[04-避坑与速查/06 网格马丁警示]] 7+1 章节 + [[04-避坑与速查/07 5 必看陷阱统一 wiki]] §3 13 经纪商反模式。**0 编造 API / 0 编造行号**。

## §1 经纪商类型差异 (4 类)

| 类型 | 点差 | 佣金 | 执行 | 适用 |
|---|---|---|---|---|
| **STP/ECN** | 0-1 点 | $3.5/手 | 市价 | 剥头皮 / EA |
| **ECN Pro** | 0 | $7/手 | 市价 | 高频 |
| **Standard** | 1.5-3 点 | 0 | 市价/挂单 | 入门 |
| **Pro** | 0.5-2 点 | 0 | 市价 | 中频 |

**EA 适用**: ECN 或 Pro, 不用 Standard (commission 0 但 spread 1.5-3 点 = 成本高)。

## §4 Filling 模式 (3 类)

| 模式 | 含义 | 适用 |
|---|---|---|
| `ORDER_FILLING_FOK` | Fill or Kill, 整笔全成或全撤 | 外汇 ECN |
| `ORDER_FILLING_IOC` | Immediate or Cancel, 能成多少算多少 | 部分 ECN |
| `ORDER_FILLING_RETURN` | 分批成交 | 老式 MM |

**怎么查 + 自动选** (M01 `_AutoSetFilling`):

```mql5
ENUM_ORDER_TYPE_FILLING GetFilling() {
   long f = SymbolInfoInteger(_Symbol, SYMBOL_FILLING_MODE);
   if (f & SYMBOL_FILLING_FOK)   return ORDER_FILLING_FOK;
   if (f & SYMBOL_FILLING_IOC)   return ORDER_FILLING_IOC;
   return ORDER_FILLING_RETURN;
}
```

## §5 跨经纪商 EA 设计原则 (6 条)

### ✅ 用 SymbolInfo 查
- `SYMBOL_FILLING_MODE` (FOK/IOC/RETURN)
- `SYMBOL_VOLUME_MIN/MAX/STEP` (手数边界)
- `SYMBOL_TRADE_TICK_SIZE/VALUE` (点价值)
- `SYMBOL_TRADE_STOPS_LEVEL` (最小止损距离)
- `SYMBOL_DIGITS` (价格小数位)
- `SYMBOL_TRADE_CONTRACT_SIZE` (合约单位)

### ❌ 不要硬编码
- "EURUSD 点差 8 点" → 别写死
- "黄金 1 手 100 oz" → 用 `SYMBOL_TRADE_CONTRACT_SIZE`
- "外汇最小手数 0.01" → 用 `SYMBOL_VOLUME_MIN`

### ✅ 用 Magic 隔离 EA
- 一个经纪商跑多个 EA, 每个 EA 自己的 magic
- 永远不要两个 EA 共用 magic (参 [[04-避坑与速查/02 OrderSend 错误码速查]] 反模式 3)

### ✅ 适配多品种
- `SymbolExist()` 检查
- 适配多种 suffix (XAUUSD / XAUUSDm / XAUUSD.m / XAUUSD.i)

### ✅ 用 Netting/Hedging 检测
- 查 `ENUM_ACCOUNT_MARGIN_MODE`
- Netting 账户: 1 品种只 1 单 (OANDA US / FXCM US)
- Hedging 账户: 1 品种多单 (Exness / IC Markets)

### ✅ 用 MQL5Kit 替代裸调
- M01 `_AutoSetFilling()` 替代硬编码 FOK
- M02 `CanOpen()` 替代手数/止损距离硬编码
- M03 `LotByRisk()` 替代 0.01 lot 硬编码
- M19 `IsInSession()` 用 `TimeCurrent()` 不做时区转换

## §6 经纪商适配建议 (5 步骤)

1. **先在目标经纪商的模拟账户上开发**
2. **每个经纪商建一个 .set 参数文件** (不同点差/合约)
3. **加自动检测 filling** (不能硬编码)
4. **加 spread 限制** (防新闻跳变)
5. **加品种存在性检查** (`SymbolExist()` 探测)

### 陷阱 5 条 (不与 80 baseline 13 err 重复, 5 段额外经纪商陷阱)

1. **0.01 lot 在 Exness micro 接受, IC Markets Raw mini 拒 (反模式 7)**:
   - ❌ 反例: 硬编码 `input double InpLot = 0.01;` IC Markets Raw Spread 0.01 = INVALID_VOLUME
   - ✅ 正例: 1) `SymbolInfoDouble(_Symbol, VOLUME_MIN)` 查最小手数, 2) `VOLUME_STEP` 查 step, 3) `MathMod(InpLot, VOLUME_STEP) == 0` 验证, 4) 用 M03 `sizing.LotByRisk(InpRiskPct, slPoints)` 算风控手数
   - 根因: 0.01 在 Exness micro OK, IC Markets Raw Spread commission $3.5/手, FXCM 0.01 账户 > $100, OANDA US 最小 0.1 lot

2. **Exness XAUUSDm vs IC Markets XAUUSD 品种名错 (反模式 8)**:
   - ❌ 反例: `SymbolInfoDouble("XAUUSD", ...)` 在 Exness = 10021 SYMBOL_NOT_FOUND
   - ✅ 正例: 1) `SymbolExist("XAUUSD") ? "XAUUSD" : SymbolExist("XAUUSDm") ? "XAUUSDm" : ...`, 2) 默认用 `Symbol()` 当前图表
   - 根因: Exness = XAUUSDm, IC Markets = XAUUSD 或 XAUUSDm, FXTM = XAUUSD, Pepperstone = XAUUSD, OANDA = XAUUSD, Tickmill = XAUUSD, FBS = XAUUSD

3. **MT5 Strategy Tester 默认 spread 固定 (反模式 10 闭环)**:
   - ❌ 反例: 回测 1 年 NFP spread 跳 30 → 180 点没模拟, 1 笔 -100 USD
   - ✅ 正例: 1) MT5 → "Execution" → "Variable spread", 2) 用经纪商历史 spread 数据, 3) M17 IsNearEvent 拦截 ±30 min
   - 根因: MT5 默认 spread 固定 = 2024 年某天的 spread 一值到底, 不会因 NFP / 流动性变化

4. **retail hedging (Exness) 1 品种多单 vs netting (OANDA) 1 品种只 1 单 (反模式 6)**:
   - ❌ 反例: EA 假设"同品种最多 1 单" (retail hedging 模式) → OANDA US netting 1 品种只 1 单 → 误判"可开仓"实际开仓后被服务器合并
   - ✅ 正例: 1) `ENUM_ACCOUNT_MARGIN_MODE` 查模式, 2) netting 账户的 `M07 HasDirection` 改成"按净持仓方向"判断
   - 根因: Exness / IC Markets hedging 一品种多单都保留; OANDA US / FXCM US netting 一品种只 1 单

5. **DST 切换 (GMT+2 欧洲夏令时 ↔ GMT+3 冬令时) 跨经纪商时区错 (反模式 11)**:
   - ❌ 反例: Exness 写死 brokerOffset=2, DST 切到 GMT+3 (11 月) 错 1 小时, 信号时点全错
   - ✅ 正例: 1) M19 SessionFilter 内部用 `TimeCurrent()` 不做时区转换, 2) M13 FileIO 写 CSV 也用 `TimeCurrent()`, 3) EA 永远不用 `TimeLocal()` + 手动 offset
   - 根因: 经纪商 DST 切换 (GMT+2 ↔ GMT+3), 硬编码 broker offset = 跨 DST 错 1 小时
