# 实盘 vs 回测差异

> **回测赚钱不代表实盘赚钱**。99% 的 EA 在回测和实盘表现有差异。

## 主要差异

| 维度 | 回测 | 实盘 |
|---|---|---|
| 滑点 | 几乎为 0 | 经常 1-5 点 |
| 点差 | 模拟固定 | 浮动（新闻时可扩大 10x）|
| 成交 | 一定能成交 | 可能被拒（库存不足）|
| 跳空 | 模拟连续 | 周一开盘跳 |
| 服务器 | 本地模拟 | 真实服务器（延迟/重连）|
| 数据 | "真实 Tick"模式近实 | 完全真实 |
| 速度 | 全速 | 真实时间 |

## 回测模式选择（策略测试器）

| 模式 | 数据 | 速度 | 真实性 |
|---|---|---|---|
| "每个报价" | 模拟生成 | 极快 | 极低 |
| "每个报价基于真实报价" | 历史 tick | 较慢 | 较高 |
| "每个报价基于 1 分钟 OHLC" | 1 分钟 K 线生成 | 中 | 中 |
| "仅开盘价" | 日线开盘 | 极快 | 极低 |
| "数学计算" | 模式自定 | 极快 | 自定 |

**推荐**：先用 "1 分钟 OHLC" 跑，OK 再用 "真实 Tick" 验证。

## 滑点问题

### 现象
- 回测：每次成交都按请求价格
- 实盘：实际成交价 ≠ 请求价

### 应对
- 设 `deviation` 容忍（建议 5-30 点）
- 突破单用限价挂单，避免市价
- 重要行情避免市价单

## 点差问题

### 现象
- 回测：固定点差
- 实盘：ECN 1-3 点，非农 50-200 点

### 应对
- 设 `MaxSpread` 过滤（参考 [[02-完整模板/EA 剥头皮模板]]）
- 非农/CPI 前暂停 EA
- 远离低流动性时段（周末/亚洲盘）

## 跳空问题

### 现象
- 周一开盘价格可能跟上周五收盘差 30-50 点
- 止损单可能"跳空"成交（按跳空价，比 SL 价还差）

### 应对
- 不在新闻/周末持仓
- 跳空敏感品种（外汇现货）周一要小心
- 设"全平时间"（如周五 23:00）

## 重连/掉线

### 现象
- 突然断网（VPS 重启、家里断电）
- 服务器端维护
- 经纪商踢出

### 应对
- VPS 上运行（比家里稳定）
- `OnTradeTransaction` 监测异常
- 心跳推送（参考 [[01-调用模块/M10 推送通知 Notify]]）

## 测试器"作弊"陷阱

### 1. 未来数据（look-ahead bias）
```mql5
// ❌ 错：用了未来 K 线
double nextClose = iClose(_Symbol, _Period, 1);   // 上一根（未来！）
if (iClose(_Symbol, _Period, 0) < nextClose) { ... }

// ✅ 对：只用当前和过去
double prevClose = iClose(_Symbol, _Period, 1);
if (iClose(_Symbol, _Period, 0) > prevClose) { ... }
```

### 2. 不切实际的成交价
- "每个报价"模式默认 `Execution=1`，永远按请求价成交
- 实盘会有滑点 → 回测要设 `deviation`

### 3. 数据不完整
- 历史 K 线在某些时段有缺失
- 高时间框架在测试器里只能从有数据的时间开始

## 必看

1. **回测至少跑 2-3 年数据**
2. **不同时间框架都测一遍**
3. **多组参数都跑一遍**（避免 overfitting）
4. **真实 Tick 模式做最终验证**
5. **永远先在模拟账户跑 1-2 周**
6. **小资金上实盘**，逐步加仓

## 测试报告关键指标

- **Total trades** < 30：样本太少，没意义
- **Profit factor** > 1.5：算及格
- **Sharpe ratio** > 0.5：算稳
- **Max drawdown** < 20%：可接受
- **Recovery factor** > 2：恢复能力强
- **Win % × Avg Win / Loss** > 1.5：盈亏比好

## 反模式（6 条不要做的事）

### 反模式 1：回测用 `last_month` 默认 1 个月就下结论

```mql5
// MT5 Strategy Tester 默认日期: "Last month"
// ❌ 1 个月数据 = 21 个交易日, 信号密度低的策略 0 笔
//   → 用户误以为"EA 有 bug", 实际是数据不够
```

**根因**：MT5 默认"Last month" = 21 个交易日。M15 均值回归策略 1 个月可能 5-15 笔, 样本不足无法判断。**回测必须至少 6-12 个月（趋势 EA）/ 2-3 年（剥头皮 EA）**。低于 30 笔 = 报告不可信。

### 反模式 2：回测用"每个 tick 基于真实 tick" 当默认

```mql5
// ❌ 错：默认就开"Every tick based on real ticks"
//   跑 1 年 XAUUSDm = 4-8 小时, 1 周调试期根本跑不完
```

**根因**："Real tick" 数据是经纪商上传的历史逐笔, 单品种 1 年 = 50-200 MB 内存 + 4-8 小时 CPU。**调试期用 "1 分钟 OHLC" 快速验证（30 秒/1 年），最终验证用 "Real tick"**。两个模式对比差异 > 30% 才有问题。

### 反模式 3：不看 `OnTester` 结果直接用回测最优参数

```mql5
// MT5 Strategy Tester "优化" 标签页 → "Optimization results" 表
// ❌ 用户看 Net Profit 排序选最优, 不看 OnTester() 输出的自定义指标
```

**根因**：MT5 默认按 Net Profit 排序选最优, 但 Net Profit 不惩罚 Max DD、不惩罚 trade count < 30。**写 EA 时实现 `OnTester()` 返回复合指标（如 `NetProfit / MathMax(MaxDD, 1) * Sqrt(Trades)`）, 用 "Custom max" 排序**。参考 [[实战/5 EA 6 月回测对比 SOP]] §3 4 维度评分。

### 反模式 4：回测最优参数直接上实盘（100% 过拟合）

```mql5
// ❌ 错：Optimization 跑出"最佳参数组合" → 直接 attach 实盘
//   99% 是过拟合: 该组参数只在特定历史区间有效
```

**根因**：Optimization 在 2024-01 ~ 2024-12 区间跑出最优, 但 2025-01 行情一变化参数失效。**必须做 Walk-Forward**：区间 1 (2024-01~06) 找最优 → 区间 2 (2024-07~12) 验证 → 区间 3 (2025-01~06) 再验证。3 个区间都通过才能上实盘。

### 反模式 5：假设 24h 流动性恒定（凌晨 3-5 点是地雷）

```mql5
// ❌ 错：XAUUSDm EA 全天 24h 跑, 凌晨 3-5 点 spread = 30-50 点
//   剥头皮 EA 在这 2 小时被 spread 拖到 -50% 收益
```

**根因**：凌晨 3-5 点（GMT）是亚洲平盘 + 欧盘未开, 流动性最低。XAUUSDm spread 正常 20-30 点 → 这 2 小时 50-100 点。**EA 默认启用 M19 SessionFilter 屏蔽非交易时段**, 凌晨/周末/节假日不开仓。参考 [[01-调用模块/M19 时段过滤 SessionFilter]]。

### 反模式 6：不区分 demo / 实盘的 server timezone

```mql5
// ❌ 错：EA 内部硬编码 "08:00-23:00" 当亚洲盘
//   部署到 GMT+2 经纪商 (Exness demo) = 实际 06:00-21:00 本地
//   M19 SetSession 用 TimeCurrent() (服务器时间) 没问题
//   但 M13 FileIO 写时间戳用 TimeLocal() → 日志时间跟 broker 不一致
```

**根因**：MT5 服务器时区各异（GMT+0/GMT+2/GMT+3），本地时间 `TimeLocal()` 跟服务器 `TimeCurrent()` 差几小时。**MQL5Kit 全部模块统一 `TimeCurrent()`（服务器时间）**, 写日志/CSV 用 `TimeCurrent()` 不用 `TimeLocal()`。CSV 落盘后用 [[01-调用模块/M11 日志 Logger]] 解析时统一转换。

### 反模式 7：回测用默认 "Every tick" 模式（模拟生成非真实 tick，耗时长）

```mql5
// MT5 Strategy Tester → "Modeling" 默认 "Every tick"
// ❌ 默认就开 Every tick = 模拟生成 tick, 1 年 XAUUSDm 跑 30 分钟
//   但 tick 是 MT5 内部按 1 分钟 OHLC 模拟生成, 不是真实逐笔 tick
```

**根因**：MT5 Strategy Tester **"Every tick"（不是 "Every tick based on real ticks"）= MT5 内部按 1 分钟 OHLC 模拟生成 tick**。**不是真实 tick**。**调试期用 "1 分钟 OHLC"（30 秒/1 年, 最低真实性）, 最终验证用 "Every tick based on real ticks"（4-8 小时/1 年, 最高真实性）**。**3 个模式对比差异 > 30% 才有问题**, 单跑 1 个模式 = 不可信。参考 [[实战/5 EA 6 月回测对比 SOP]] §3 模式选择表（"1 分钟 OHLC" 默认 + 真实 tick 终验）。

### 反模式 8：实盘有滑点但回测 `deviation=0` + `execution=1`（回测 100% 成交 vs 实盘 80%）

```mql5
// MT5 Strategy Tester 默认 Execution=1 (Normal) = 永远按请求价成交
// ❌ 回测 deviation=0, 所有 OrderSend 100% 按请求价成交
//   实盘 deviation=0 = 99% PRICE_CHANGED (10020) 拒单 (参 [[04-避坑与速查/02 OrderSend 错误码速查]] 反模式 2)
```

**根因**：MT5 回测 Execution 模式 = **默认模拟无滑点**, 实盘 = 一定滑点（XAUUSDm 实盘平均 0.5-2 点, NFP 5-30 点）。**回测设置 `execution=2 (delayed)` + `deviation=30` 模拟真实滑点**。**回测 "Profit Factor > 1.5" 的 EA, 实盘打 7 折 = PF 1.05（不显著）**。**任何 EA 上实盘前必须回测开 delayed execution 跑一次, 对比 normal execution 差 > 20% 的 EA 上实盘必亏**。

### 反模式 9：隔夜跳空回测不模拟（周一开盘 gap 30-50 点）

```mql5
// ❌ MT5 Strategy Tester 默认不模拟"周末 gap", 周一开盘 = 上周五收盘价
//   实盘周一开盘 = 上周五收盘价 ± 30-50 点 (XAUUSDm) / 100-200 点 (BTCUSD)
//   趋势 EA 的 SL 跳空成交 = 比 SL 价还差 30-50 点
```

**根因**：MT5 回测引擎**默认不模拟周末跳空**, 周一开盘 K 线从上周五收盘价开始（= 无 gap）。**实盘周一开盘可能 gap 30-50 点（XAUUSDm）/ 100-200 点（BTCUSD）/ 50-100 pips（外汇）**。**回测不开 "Weekend gap simulation" = 回测无跳空风险, 实盘必爆**。**MT5 Strategy Tester → "Execution" → 勾 "Weekend gap simulation"**。M19 SessionFilter 周五收盘前 30 min 全平 = 减少跳空敞口（参 [[06 网格马丁警示]] §5 陷阱 5）。

### 反模式 10：spread 浮动回测不模拟（非农 50-200 点 spread 跳变）

```mql5
// ❌ MT5 Strategy Tester 默认 spread 固定（按交易品种设置文件, 不会变）
//   实盘 NFP / CPI / FOMC 前后 spread 跳 30-200 点, 1 笔就 -100 USD
//   剥头皮 EA 在新闻 spread 跳变时 1 笔就吃掉 1 周盈利
```

**根因**：MT5 回测默认 spread 固定 = 用 2024 年某天的 spread 一值到底（不会因 NFP / 流动性变化）。**实盘非农 1 分钟 spread 跳 50-200 点, 1 笔就 -100 USD**。**回测开 "Variable spread" + 用经纪商历史 spread 数据**（不是默认固定 spread）。**任何 EA 回测必看 "Max spread" 列, 超过 50 点的非农时段必过滤**。M17 NewsFilter `IsNearEvent(30, 30, _Symbol)` 在 ±30 min 新闻期不开仓 = 直接绕开 spread 跳变。参考 [[04-避坑与速查/02 OrderSend 错误码速查]] 反模式 2（`deviation` 不设）+ [[01-调用模块/M17 新闻过滤 NewsFilter]] 7 章节 spec。

### 陷阱 5 条 (不与 80 baseline 11 err 重复, 5 段额外实盘陷阱)

1. **回测 "1 分钟 OHLC" 模式 vs "Every tick based on real ticks" 模式 差异 > 30% 时未察觉**:
   - ❌ 反例: 跑 1 分钟 OHLC 模式 + deviation=0 → 回测 OK → 实盘 80% 拒单 (10020 PRICE_CHANGED)
   - ✅ 正例: 1 分钟 OHLC 跑 OK 后, 切 "Every tick based on real ticks" + `execution=2 (delayed)` + `deviation=30` 终验, 两模式差异 > 30% 必有 bug
   - 根因: 1 分钟 OHLC 模式 = MT5 内部模拟, 跟实盘真实 tick 序列差异大

2. **Optimization 跑 1 年找到最优参数 → 直接上实盘 (100% 过拟合)**:
   - ❌ 反例: 跑 2024-01 ~ 2024-12 找最优, 2025-01 实盘 = 参数失效爆仓
   - ✅ 正例: 区间 1 (2024-01~06) 找最优 → 区间 2 (2024-07~12) 验证 → 区间 3 (2025-01~06) 再验证, 3 区间都通过才上实盘
   - 根因: 1 年最优参数只对该年行情有效, 跨年行情变化 (黑天鹅 / 政策 / 利率) = 失效

3. **回测 "Profit Factor 1.5" 实盘打 7 折 = PF 1.05 (不显著)**:
   - ❌ 反例: 回测 PF 1.5 → 用户以为赚钱 → 实盘 1 个月 0 笔
   - ✅ 正例: 回测 PF 1.5 + 实盘打 7 折 (考虑 spread / commission / 滑点) = 0.5 显著度, 必查 Max DD
   - 根因: 回测按请求价成交, 实盘有 spread + commission + 滑点, 3 项吃掉 30% 盈利

4. **NFP 1 分钟 spread 跳 30 → 180 点, 1 笔就 -100 USD (M17 未接)**:
   - ❌ 反例: EA 默认 24h 跑, NFP ±30 min 没 M17 拦截 = 1 笔亏 1 周盈利
   - ✅ 正例: M17.IsNearEvent(30, 30, _Symbol) 拦截 ±30 min NFP/CPI/FOMC, 实测 MaxDD 降 13pp (参 [[M17 实战段 §5.4 案例 3]])
   - 根因: NFP 公布瞬间 spread 跳 30 → 180 点, 1 秒波动 100+ 点, EA 撞上必亏

5. **EA 跑 3 天突然"不成交" (VPS 重启 / 经纪商断 / EA 死锁), 0 心跳 = 黑盒**:
   - ❌ 反例: OnInit 0 EventSetTimer, EA 死锁 3 天不发现
   - ✅ 正例: L79/L981 OnInit 调 `EventSetTimer(300)` + M11.Logger.Info("heartbeat", msg) + Comment() 屏幕显示, 5 min 间隔 = 24h 288 行日志
   - 根因: 0 心跳 = EA 跑不跑都不知道, 心跳缺失立即发现死锁/断网/重启
