# 通用片段 - 下单

> 一段段可复制的下单代码，用在 EA 各处。

## 开多（最简版）

```mql5
double ask = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
MqlTradeRequest req = {};
MqlTradeResult  res = {};
req.action    = TRADE_ACTION_DEAL;
req.symbol    = _Symbol;
req.volume    = 0.01;
req.type      = ORDER_TYPE_BUY;
req.price     = ask;
req.deviation = 30;
req.magic     = 20260101;
req.type_filling = ORDER_FILLING_FOK;
if (OrderSend(req, res)) {
   if (res.retcode == TRADE_RETCODE_DONE)
      Print("BUY OK #", res.order, " @", res.price);
   else
      Print("BUY retcode=", res.retcode, " ", res.comment);
} else {
   Print("BUY send failed err=", GetLastError());
}
```

```mql5

req.volume   = PositionGetDouble(POSITION_VOLUME);
// 反向
if (PositionGetInteger(POSITION_TYPE) == POSITION_TYPE_BUY) {
   req.type  = ORDER_TYPE_SELL;
   req.price = SymbolInfoDouble(_Symbol, SYMBOL_BID);
} else {
   req.type  = ORDER_TYPE_BUY;
   req.price = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
}
req.deviation = 30;
OrderSend(req, res);
```

```mql5
for (int i = PositionsTotal() - 1; i >= 0; i--) {
   ulong t = PositionGetTicket(i);
```

## 反手（一笔单翻转方向）

```mql5
// 平掉再开反方向
void Reverse(ulong ticket) {
   if (!PositionSelectByTicket(ticket)) return;
   double vol = PositionGetDouble(POSITION_VOLUME);
   ENUM_POSITION_TYPE oldType =
      (ENUM_POSITION_TYPE)PositionGetInteger(POSITION_TYPE);
   ENUM_ORDER_TYPE newType = (oldType == POSITION_TYPE_BUY)
                           ? ORDER_TYPE_SELL
                           : ORDER_TYPE_BUY;
   // 1) 平旧
   ClosePos(ticket);
   // 2) 开新
   OpenPos(newType, vol);
}
```

## 加仓（在已有同方向持仓基础上）

```mql5
// 简化版：直接加倍
void AddToPosition(ulong ticket, double extraLot) {
   ENUM_POSITION_TYPE type =
      (ENUM_POSITION_TYPE)PositionGetInteger(POSITION_TYPE);
   ENUM_ORDER_TYPE orderType = (type == POSITION_TYPE_BUY)
                             ? ORDER_TYPE_BUY : ORDER_TYPE_SELL;
   OpenPos(orderType, extraLot);
}
```

## 必看
- **永远检查 `retcode`**，不是看 OrderSend 的 bool 返回
- `type_filling` 必须正确（见 [[04-避坑与速查/04 经纪商差异-点差-手续费]]）
- 任何价格要 `NormalizeDouble(price, _Digits)`
- 滑点不要设太大（会被经纪商打回）

```mql5
void OpenPos(ENUM_ORDER_TYPE type, double price) {
   double sl = (type == ORDER_TYPE_BUY) ? price - SL_Points * _Point
                                       : price + SL_Points * _Point;
   double tp = (type == ORDER_TYPE_BUY) ? price + TP_Points * _Point
                                       : price - TP_Points * _Point;
   double slDist = MathAbs(price - sl);
   double lot = sizing.LotByRisk(RiskPct, slDist);     // M03 算手数
   if (lot <= 0) return;
   if (!risk.CanOpen(type, lot, sl, tp)) return;      // M02 风控前置
   if (type == ORDER_TYPE_BUY) {
      if (trade.Buy(lot, sl, tp, "MR_Long"))           // M01 封装
         logger.Trade("BUY", _Symbol, lot, price, 0, "超卖做多");
   } else {
      if (trade.Sell(lot, sl, tp, "MR_Short"))        // M01 封装
         logger.Trade("SELL", _Symbol, lot, price, 0, "超买做空");
   }
}
```

**典型代码段 (L745-784 完整 TryOpen 函数 10 步流程)**:

```mql5
void TryOpen(ENUM_ORDER_TYPE type) {
   // 1. 取价
   double ask = SymbolInfoDouble(_Symbol, SYMBOL_ASK);
   double bid = SymbolInfoDouble(_Symbol, SYMBOL_BID);
   if (ask == 0 || bid == 0) return;
   double price = (type == ORDER_TYPE_BUY) ? ask : bid;
   // 2. 算 SL/TP
   double slRaw = (type == ORDER_TYPE_BUY) ? price - InpSlPoints * _Point
                                           : price + InpSlPoints * _Point;
   double tpRaw = (type == ORDER_TYPE_BUY) ? price + InpTpPoints * _Point
                                           : price - InpTpPoints * _Point;
   // 3. NormalizeDouble (必查清单, 避免 ERR 10018)
   double slPrice = NormalizeDouble(slRaw, _Digits);
   double tpPrice = NormalizeDouble(tpRaw, _Digits);
   // 4. 最小止损距离检查 (避免 ERR 130)
   long stopLevel = SymbolInfoInteger(_Symbol, SYMBOL_TRADE_STOPS_LEVEL);
   double minDist  = stopLevel * _Point;
   if (MathAbs(price - slPrice) < minDist) {
      PrintFormat("SL 太小 (%.5f < %.5f), 跳过", MathAbs(price - slPrice), minDist);
      return;
   }
   // 5. 算手数
   double slDist = MathAbs(price - slPrice);
   double lot = sizing.LotByRisk(InpRiskPercent / 100.0, slDist);
   if (lot <= 0) return;
   // 6. HasDirection 防同向重复
   if (type == ORDER_TYPE_BUY && CPositions::HasDirection(InpMagicNumber, POSITION_TYPE_BUY)) return;
   if (type == ORDER_TYPE_SELL && CPositions::HasDirection(InpMagicNumber, POSITION_TYPE_SELL)) return;
   // 7. M02 风控前置
   if (!risk.CanOpen(type, lot, slPrice, tpPrice)) return;
   // 8. M01 封装调用
   bool ok = false;
   if (type == ORDER_TYPE_BUY) ok = trade.Buy(lot, slPrice, tpPrice, InpEAComment);
   else                          ok = trade.Sell(lot, slPrice, tpPrice, InpEAComment);
   // 9. 频率控制 + 10. logger.Trade + M10 通知
   if (ok) {
      OnTradeOpened();
      logger.Trade(type == ORDER_TYPE_BUY ? "BUY" : "SELL", _Symbol, lot, price, 0, InpEAComment);
      if (InpEnableNotify)
         M10.Trade(type == ORDER_TYPE_BUY ? "BUY" : "SELL", _Symbol, price, lot, 0, InpEAComment);
   }
}
```

### 陷阱 (5 条, 来自 6 demo 实测)

1. **裸 OrderSend 4/5 位不兼容, ERR 10018 invalid fill** (01 spec L13-33 教学版):
   - ❌ 反例: `req.type_filling = ORDER_FILLING_FOK; OrderSend(req, res);` — Exness XAUUSDm Hedge 是 IOC 不是 FOK, 报 ERR 10018 invalid fill
   - ✅ 正例: 用 M01.CTradePlus.Buy, M01 内部自动测 SymbolInfoInteger(SYMBOL_FILLING_MODE), 选 IOC / FOK / RETURN, 0 错
   - 修复: 全 EA 搜 `OrderSend` 替换为 `trade.Buy` / `trade.Sell` / `trade.ClosePos` (1 行正则替换)

2. **先下单后风控, 已经成交才风控没用** (01 spec L201 MeanRev 正确 / L774 Scalper 正确, 反例见 5 必看陷阱 wiki §2):
   - ❌ 反例: `trade.Buy(...); if (drawdown > 0.05) CloseAll();` — 已经成交再判断, 单笔已亏
   - ✅ 正例: `if (!risk.CanOpen(type, lot, sl, tp)) return; if (trade.Buy(...)) logger.Trade(...);` (L199 / L771) — M02 风控前置, 0 成交先判断
   - 根因: 01 spec demo 没强调"风控前置", 实物必须 M02.CanOpen 在 trade.Buy 之前

3. **0 M01 封装, 100% 裸 OrderSend** (ScalperXAUv5simple L135-138 仍用 M01 封装, 0 裸调用):
   - ❌ 反例 (01 spec L13-33 / L37-50 / L52-71): 全部 MqlTradeRequest + OrderSend, 0 magic 0 滑点 0 重试
   - ✅ 正例 (6 demo 100% 命中): 8 EA 中 8 EA 全部用 M01.CTradePlus 封装, 0 段走裸 OrderSend
   - 修复: 任何新 EA 第 1 步 include `<MQL5Kit/Trade/CTradePlus.mqh>`, 0 写裸 MqlTradeRequest

4. **OnInit 时挂 TrailingStop, 太早** (01 spec 0 强调 / 5 必看陷阱 wiki §1):
   - ❌ 反例: `int OnInit() { trail.Init(&trade, Magic); trail.Apply(); }` — OnInit 时还没有持仓, trail.Apply 0 效果
   - ✅ 正例: `void OnTick() { if (UseTrailing) { _UpdateTrailParams(); trail.Apply(); } }` (MeanRev L142-145) — OnTick 每 tick 算 ATR 阈值, 然后调 trail.Apply
   - 根因: M08.TrailingStop 是"开仓后才有 SL 跟踪", OnInit 调 trail.Apply 0 意义

5. **0 demo 频次 0 P2 简化版, 实际 100% 接入** (ScalperXAUv5simple L137 简化版 + ScalperXAU L774 完整版对比):
   - ❌ 反例 (L137 v5simple): `trade.Init(InpMagicNumber, 30); trade.Buy(0.01, slPrice, tpPrice, "v5simple");` — 0 risk 0 position 0 log, debug 简化版, 生产 0 准
   - ✅ 正例 (L774 Scalper 完整 10 步): 0 漏 4 段 (取价/算 SL-TP/NormalizeDouble/MinStopLevel/M03 算手数/HasDirection/M02 风控/M01/M10/logger), 11 段完整流程
   - 修复: v5simple 实际是 debug 期 throwaway 验证, 生产 EA 必走完整 10 步流程 (ScalperXAU L745-784 范本)
