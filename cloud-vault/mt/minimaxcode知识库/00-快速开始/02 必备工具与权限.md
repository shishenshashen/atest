# 必备工具与权限

## 工具链

| 工具               | 版本要求      | 用途              | 备注                       |
| ---------------- | --------- | --------------- | ------------------------ |
| PowerShell       | 5.1+（自带）  | 所有脚本            | 不兼容 PS 7 的 `$_` 解析逻辑     |
| mavis CLI        | latest    | 启动 daemon / agent | 安装后 `mavis` 在 PATH         |
| git              | 2.30+     | 克隆 Hermes       | 国内网络用镜像前缀（见 [[04-踩坑速查表/03 网络与 Git 踩坑]]） |
| schtasks / 任务计划程序 | 系统自带       | 开机自启            | `schtasks /Create` 配合 `Register-ScheduledTask` |
| 文本编辑器           | Obsidian 推荐 | 读写 markdown     | 保持 UTF-8 **无 BOM**（关键）   |

## 端口

| 端口      | 用途                       |
| ------- | ------------------------ |
| 15321   | mavis daemon（默认）          |
| 自定义     | 其他 MCP server             |

## UAC / 管理员权限

```powershell
# 检查是否管理员
([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()
).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
```

- **计划任务 / 服务** 必须管理员运行 PowerShell。
- **CU 操作** 不需要管理员，但必须 console session（见下）。

## RDP Session 限制（关键）

CU 的 `desktop_screenshot` / `desktop_zoom` / `desktop_screenshot_region` 走 nut.js native binding，**RDP session（session 2+）会抛 "Failed to capture screen"**。

- ✅ **本地 console session（session 1）**：截屏、点击、键入全部正常
- ❌ **RDP session（session 2+）**：仅 `desktop_window_list` 可用

> GUI 操作类任务（点 MetaEditor F7、点交易软件下单按钮）必须由 console session 里的用户/工具执行。

## 文件编码

PowerShell 5.1 对 UTF-8 BOM 极度敏感——多个 BOM 会让脚本在奇怪位置报语法错（`"在表达式中发现意外的标记"}""`）。

**写文件安全姿势**：

```powershell
# 方案 1：.NET
[System.IO.File]::WriteAllText(
  "C:\path\to\file.ps1",
  $content,
  [System.Text.UTF8Encoding]::new($false)   # $false = 不要 BOM
)

# 方案 2：先读再写（自动去 BOM）
Get-Content "C:\path\to\file.ps1" | Set-Content -Encoding UTF8NoBOM
```

## 必备环境变量

```powershell
# 可选：自定义 daemon 端口
$env:MAVIS_PORT = "15321"

# 可选：自定义 agent 工作目录
$env:MAVIS_WORKSPACE = "C:\Users\Administrator\.mavis\sessions"
```
