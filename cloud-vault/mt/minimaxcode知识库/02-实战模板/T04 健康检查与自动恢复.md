# T04 健康检查与自动恢复

## 场景

daemon 进程挂掉 / 端口占用 / CU 被关 —— 你不在电脑旁，**脚本自愈** + 告警到 IM。

## 文件

保存为 `C:\Users\Administrator\.mavis\bin\mavis-healthcheck.ps1`：

```powershell
<#
.SYNOPSIS
  mavis daemon / CU 全链路健康检查 + 自愈
.DESCRIPTION
  每 60s 跑一次：
    1. 端口 15321 TCP 可达？
    2. daemon 进程在？
    3. CU enabled？
    4. workspaceDir 可写？
  任何一项失败 → 自愈 → 写日志 → 可选飞书告警
#>

$ErrorActionPreference = "Continue"
$LogDir    = "C:\Users\Administrator\.mavis\logs"
$LogFile   = Join-Path $LogDir "mavis-healthcheck.log"
$DaemonUrl = "http://localhost:15321"
$Workspace = "C:\Users\Administrator\.mavis\sessions"
$FeishuHookUrl = $env:FEISHU_WEBHOOK_URL  # 可选：飞书机器人 webhook

if (-not (Test-Path $LogDir)) {
  New-Item -ItemType Directory -Force -Path $LogDir | Out-Null
}

function Write-Log($level, $msg) {
  $line = "{0} [{1}] [{2}] {3}" -f (Get-Date -Format "yyyy-MM-dd HH:mm:ss"), $PID, $level, $msg
  Add-Content -Path $LogFile -Value $line -Encoding UTF8
  if ($level -eq "ERROR") { Write-Host $line -ForegroundColor Red }
  else { Write-Host $line }
}

function Send-FeishuAlert($msg) {
  if (-not $FeishuHookUrl) { return }
  try {
    $body = @{ msg_type = "text"; content = @{ text = "[mavis-healthcheck] $msg" } } `
      | ConvertTo-Json -Compress -Depth 5
    Invoke-WebRequest -Method POST -Uri $FeishuHookUrl `
      -Body $body -ContentType "application/json" `
      -TimeoutSec 5 -UseBasicParsing | Out-Null
  } catch {
    Write-Log "WARN" "feishu alert failed: $($_.Exception.Message)"
  }
}

function Test-Port {
  param([string]$Host = "localhost", [int]$Port = 15321, [int]$TimeoutMs = 2000)
  try {
    $tcp = New-Object System.Net.Sockets.TcpClient
    $iar = $tcp.BeginConnect($Host, $Port, $null, $null)
    $ok = $iar.AsyncWaitHandle.WaitOne($TimeoutMs, $false)
    if ($ok) {
      $tcp.EndConnect($iar); $tcp.Close()
      return $true
    }
    $tcp.Close()
    return $false
  } catch { return $false }
}

function Get-CuStatus {
  try {
    $resp = Invoke-WebRequest -Uri "$DaemonUrl/mavis/api/cu/enabled" `
      -UseBasicParsing -TimeoutSec 3
    return ($resp.Content | ConvertFrom-Json)
  } catch { return $null }
}

function Set-CuEnabled([bool]$enabled) {
  $body = @{enabled=$enabled; workspaceDir=$Workspace} | ConvertTo-Json -Compress
  Invoke-WebRequest -Method PUT -Uri "$DaemonUrl/mavis/api/cu/enabled" `
    -Body $body -ContentType "application/json" -UseBasicParsing -TimeoutSec 5 `
    | Out-Null
}

function Start-Daemon {
  try {
    mavis daemon start
    Start-Sleep -Seconds 5
    return $true
  } catch {
    Write-Log "ERROR" "mavis daemon start failed: $($_.Exception.Message)"
    return $false
  }
}

# ============= 主循环 =============

$LastCuEnabledState = $null
Write-Log "INFO" "=== mavis-healthcheck started ==="

while ($true) {
  $failed = @()

  # 1. 端口检查
  if (-not (Test-Port)) {
    $failed += "port 15321 unreachable"
    Write-Log "ERROR" "port 15321 unreachable"
    if (Start-Daemon) {
      $failed = @()  # 重启后清空
      Write-Log "INFO" "daemon restarted by healthcheck"
    }
  }

  # 2. 进程检查
  $proc = Get-Process -Name mavis -ErrorAction SilentlyContinue
  if (-not $proc) {
    $failed += "mavis process not found"
    Write-Log "ERROR" "mavis process not found"
    if (Start-Daemon) { $failed = @(); Write-Log "INFO" "daemon restarted" }
  }

  # 3. CU 状态
  $cu = Get-CuStatus
  if ($null -eq $cu) {
    $failed += "cu status query failed"
  } elseif (-not $cu.enabled) {
    $failed += "cu disabled"
    if ($LastCuEnabledState -ne $false) {
      Write-Log "WARN" "cu disabled, attempting to re-enable"
      try {
        Set-CuEnabled $true
        Write-Log "INFO" "cu re-enabled"
      } catch {
        Write-Log "ERROR" "cu re-enable failed: $($_.Exception.Message)"
      }
    }
  } else {
    if ($LastCuEnabledState -ne $true) {
      Write-Log "INFO" "cu enabled=true (workspaceDir=$($cu.workspaceDir))"
    }
  }
  $LastCuEnabledState = $cu.enabled

  # 4. workspace 可写
  if (-not (Test-Path $Workspace)) {
    New-Item -ItemType Directory -Force -Path $Workspace | Out-Null
    Write-Log "WARN" "workspace created: $Workspace"
  }
  $testFile = Join-Path $Workspace ".healthcheck.tmp"
  try {
    "ok" | Out-File -FilePath $testFile -Encoding utf8 -ErrorAction Stop
    Remove-Item $testFile -Force -ErrorAction SilentlyContinue
  } catch {
    $failed += "workspace not writable"
    Write-Log "ERROR" "workspace not writable: $Workspace"
  }

  # 5. 告警（聚合，60s 一次不刷屏）
  if ($failed.Count -gt 0) {
    $alert = "[$((Get-Date).ToString('HH:mm:ss'))] FAIL: " + ($failed -join "; ")
    Write-Log "ERROR" $alert
    Send-FeishuAlert $alert
  }

  Start-Sleep -Seconds 60
}
```

## 注册为计划任务

```powershell
$script = "C:\Users\Administrator\.mavis\bin\mavis-healthcheck.ps1"
schtasks /Create /TN MavisHealthCheck /SC ONSTART /RL HIGHEST /RU SYSTEM `
  /TR "powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File `"$script`"" `
  /F | Out-Null

# 补充 RestartCount（参考 T02）
$task = Get-ScheduledTask -TaskName MavisHealthCheck
$task.Settings.RestartCount = 5
$task.Settings.RestartInterval = "PT2M"
$task | Set-ScheduledTask | Out-Null
```

## 三档健康状态

| 状态     | 触发                | 处理                |
| ------ | ----------------- | ----------------- |
| 绿色     | 端口通 + 进程在 + CU 开  | 只写心跳日志            |
| 黄色     | CU 被关 / workspace 满 | 自愈一次（PUT 翻 true）   |
| 红色     | 端口死 / 进程没 / 自愈失败  | 自愈 + 飞书告警 + 写错误栈 |

## 验证

```powershell
# 1. 手动跑一次
powershell -NoProfile -File C:\Users\Administrator\.mavis\bin\mavis-healthcheck.ps1

# 2. 看日志
Get-Content C:\Users\Administrator\.mavis\logs\mavis-healthcheck.log -Tail 20

# 3. 制造一次失败（手动停 daemon）
mavis daemon stop
Start-Sleep -Seconds 70
# 看 healthcheck 是否自动重启
Get-Content C:\Users\Administrator\.mavis\logs\mavis-healthcheck.log -Tail 20
```

## 调参

| 参数            | 默认      | 调整理由                          |
| ------------- | ------- | ----------------------------- |
| `Start-Sleep` | 60s     | 紧（30s）→ 自愈更及时；松（300s）→ 日志干净 |
| `Test-Port` 超时 | 2000ms  | 网络抖动大时可调 5000ms               |
| 自愈次数          | 1       | 连续失败 N 次告警，避免 daemon 死循环重启  |

## 与 T01 keep-alive 的关系

| 脚本                | 关注点              | 不关注         |
| ----------------- | ---------------- | ----------- |
| `T01 cu-keepalive` | CU 一直保持 enabled  | 端口 / 进程     |
| `T04 healthcheck`  | 端口 / 进程 / CU 全链路 | CU 翻转频率     |

> 两者**并存**运行：T01 负责"常开"，T04 负责"挂掉就拉起"。

## 高级：多 daemon 实例监控

如果有多个 daemon（开发 + 生产），复制脚本、改 `$DaemonUrl` + `$Port` 即可：

```powershell
# 同时跑多个：传 instance 名
param([string]$Instance = "default")
$Cfg = Get-Content "C:\Users\Administrator\.mavis\config\instances.json" `
       | ConvertFrom-Json
$DaemonUrl = "http://localhost:$($Cfg.$Instance.port)"
```
