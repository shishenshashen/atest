# T02 开机自启计划任务

## 场景

需要"开机就自动跑、断电能恢复、永不退出"的脚本：

- CU keep-alive 守护
- 行情 / 交易数据同步
- 任何"我不在电脑旁也要跑"的活

## 推荐方案：`schtasks` + `Register-ScheduledTask` 组合

只用 `schtasks` **无法**设 `RestartCount` / `RestartInterval`——必须再调一次 `Register-ScheduledTask`。

### 完整脚本（管理员 PowerShell）

```powershell
<#
.SYNOPSIS
  注册一个开机自启 + 失败自动重启的计划任务
.PARAMETER TaskName
  任务名（英文 + - 或 _，不含空格）
.PARAMETER ScriptPath
  要跑的 .ps1 绝对路径
.PARAMETER RunAsSystem
  默认 $true（以 SYSTEM 身份跑，不需登录）
#>

param(
  [Parameter(Mandatory)] [string]$TaskName,
  [Parameter(Mandatory)] [string]$ScriptPath,
  [bool]$RunAsSystem = $true
)

# 1. 先用 schtasks 创建基础任务（-Delay 不可用，所以不传）
schtasks /Create `
  /TN $TaskName `
  /SC ONSTART `
  /RL HIGHEST `
  /RU $(if ($RunAsSystem) { "SYSTEM" } else { "$env:USERDOMAIN\$env:USERNAME" }) `
  /TR "powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File `"$ScriptPath`"" `
  /F | Out-Null

# 2. 再用 PowerShell 补充 RestartCount / RestartInterval
$task = Get-ScheduledTask -TaskName $TaskName
$task.Settings.RestartCount = 3
$task.Settings.RestartInterval = "PT1M"   # ISO 8601 duration，1 分钟
$task.Settings.AllowStartIfOnBatteries = $true
$task.Settings.DontStopIfGoingOnBatteries = $true
$task.Settings.MultipleInstances = "Parallel"
$task | Set-ScheduledTask | Out-Null

Write-Host "Task registered: $TaskName"
```

## 关键事实（来自踩坑）

| 陷阱          | 说明                                                                   |
| ----------- | -------------------------------------------------------------------- |
| `-Delay` 参数 | PowerShell 5.1 的 `New-ScheduledTaskTrigger -AtStartup -Delay` **不支持**——报参数错 |
| `RestartCount` | `schtasks` 不支持——必须 `Register-ScheduledTask` 后 `Set-ScheduledTask`         |
| `RestartInterval` | ISO 8601 duration 字符串（`"PT1M"` = 1 分钟，`"PT5M"` = 5 分钟）                 |
| 用户上下文       | 用 `SYSTEM` 跑 = 不需要登录、不会因为密码过期停跑，但看不到用户桌面（**CU 不能用 SYSTEM 跑**）         |
| 工作目录        | 任务运行时工作目录是 `C:\Windows\System32`，不是脚本所在目录——脚本里必须用绝对路径                |

## 验证清单

```powershell
# 看任务存在
Get-ScheduledTask -TaskName "MavisCUKeepAlive"

# 看下次触发时间
(Get-ScheduledTask -TaskName "MavisCUKeepAlive").NextRunTime

# 看运行历史（最近 5 次）
Get-ScheduledTask -TaskName "MavisCUKeepAlive" | Get-ScheduledTaskInfo

# 手动触发
Start-ScheduledTask -TaskName "MavisCUKeepAlive"

# 立即停止
Stop-ScheduledTask -TaskName "MavisCUKeepAlive"

# 注销
Unregister-ScheduledTask -TaskName "MavisCUKeepAlive" -Confirm:$false
```

## 特殊场景

### 跑 GUI / CU 任务

CU 必须在 console session 跑，SYSTEM 身份在 session 0 隔离，**CU 会失败**。两种解法：

1. **用户登录触发**：把 trigger 改成 `-AtLogOn` 而非 `-AtStartup`
2. **任务计划程序 UI**：「只在用户登录时运行」勾上，「用户已登录」触发

### 看日志

```powershell
# 计划任务自己的日志
Get-WinEvent -LogName "Microsoft-Windows-TaskScheduler/Operational" |
  Where-Object { $_.Message -like "*MavisCUKeepAlive*" } |
  Select-Object -First 20
```

### 排错：脚本不跑

1. 任务历史显示 "Could not start" → 看脚本路径 / 权限
2. 任务历史显示 "Running" 但实际没效果 → 脚本静默失败 → 在脚本里加 `Start-Transcript`
3. 重启后没自动跑 → 检查 trigger 是否 `AtStartup`（不是 `AtLogOn`）
