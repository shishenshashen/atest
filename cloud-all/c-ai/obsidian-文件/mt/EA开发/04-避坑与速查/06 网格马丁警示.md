## 1. 什么是网格马丁（定义 / 变种 / 共性）

### 1.1 定义

**网格（Grid）** = 价格跌破 X 点就开新仓，形成等间距的"网格"。**马丁格尔（Martingale）** = 每次新仓手数加倍，赌"价格必然回归"。两者组合就是"网格马丁"——剥头皮 + 顺势加仓 + 均价止盈，**胜在胜率高（80%+），败在一次单边市就爆仓**。

### 1.2 三大变种

| 变种 | 加仓规则 | 风险曲线 | 典型 EA |
|---|---|---|---|
| **等比** (geometric) | `lot_n = lot_0 × r^(n-1)`, r=2 最常见 | 指数级 — 第 5 层 16x 首单手数 | [[02-完整模板/EA 网格马丁模板]] line 122-129 `MathPow(LotMultiplier, n)` |
| **等差** (arithmetic) | `lot_n = lot_0 + step × (n-1)` | 线性级 — 第 5 层 5x 首单手数 | `ScalpingMartin_EA.mq5` line 947-955 `switch(g_current_level)` 用 0.01/0.02/0.03/0.05/0.08 |
| **斐波那契** (Fibonacci) | `lot_n = lot_0 × Fib(n)`, 1,1,2,3,5,8,13... | 介于等比-等差之间 — 第 6 层 13x | 公开 EA 较少（部分 EA 商店专有） |

### 1.3 三大共性

无论变种，**所有网格马丁都有 3 个共性**：

1. **亏损不设上限**：默认 "HardStopLoss = 0" 时, 单边行情 1000 点可亏掉全部累计仓位
2. **胜率极高但盈亏比极差**：1 次盈利 100 美元对 5 次亏损 80 美元, 总账 +20 美元, 但 1 次单边市可以倒亏 5,000 美元
3. **回测欺骗性极强**：回测 5 年可能 4 年 11 月都是 +20%, 最后 1 个月 -800%（黑天鹅）

## 2. 6 个永远不要（核心警示）

> **本节是本 wiki 最重要的章节**。每个 "永远不要" 都来自 [[02-完整模板/EA 网格马丁模板]] 实物 + `ScalpingMartin_EA.mq5` v1.5 实物的 1,287 行代码 + 真实账户回测 1 年的踩坑经验。

### 永远不要 1：永远不要全仓跑（资金必须 < 30%）

```mql5
// ❌ 错：账户 1,000 USD, EA 默认手数 0.01, 看起来"小"
//   实际：5 层加仓累计手数 0.31, 单边 200 点 = -620 USD = 62% 爆仓
input double Initial_Lot = 0.01;       // 看似小, 5 层累计 0.31 lot
input int    Max_Levels  = 5;          // 5 层加仓
// XAUUSDm 1 lot 1 点 = $1, 200 点 × 0.31 = $62, 但 1 账户 = $62/1000 = 6.2%?
// ❌ 错！加仓均价不断拉高, 实际亏损远超 200 点 × 0.31

// ✅ 对：账户 ≥ 10,000 USD 才能跑 0.01 起 + 5 层
//   或者手数降到 0.001 (broker 允许), 但 0.001 多数 ECN 不让
```

**根因**：网格马丁**盈亏非线性**——前 4 层都赚小钱, 第 5 层 1 单亏前 4 单的累计。**资金 < 30% 等于"半仓马丁"** = 把赌博放大 3 倍。**实际安全线是 账户 ≥ 10x 单边最大亏损**, 不是 30%。

### 永远不要 2：永远不要在新闻 / 非农 / CPI 前运行

```mql5
// ScalpingMartin_EA.mq5 line 107:
// TODO: 新闻过滤 — 未来版本中实现重要经济数据前后静默期, 需接入经济日历API
//   → V1.5 还没接 M17, 用户的"提示"提醒未来做
```

**根因**：NFP / CPI / FOMC 前 30 分钟 + 后 30 分钟, XAUUSDm spread 跳到 50-200 点, 价格 1 秒波动 100+ 点。**网格马丁的"加仓触发"会在新闻瞬间连开 3-5 单**, 全部以最差价成交 = 滑点 -500 点 × 累计手数 = 直接爆仓。**M17 NewsFilter ±30 min 必须接**, [[01-调用模块/M17 新闻过滤 NewsFilter]] 有完整 7 章节 spec。

### 永远不要 3：永远不要假设"均价止盈"一定能打回

```mql5
// [[02-完整模板/EA 网格马丁模板]] line 170-181:
if (dir == POSITION_TYPE_BUY && bid >= avgPrice + TP_AvgPips * _Point)
   takeProfit = true;
//   ❌ 错：默认 TP_AvgPips=100 点
//   但 XAUUSDm 2024 年单边下跌 800 点持续 2 周, 永远回不到均价 + 100
```

**根因**：均价止盈 = 假设"价格必然回归"。**单边行情 800-2000 点时, 这个假设完全失败**, 累计 5-10 单全部浮亏 → 触发硬止损 → 全平巨亏。**马丁 EA 在震荡市稳赚, 在趋势市必爆**。**没有 100% 可靠的"硬止损"可以救马丁**——硬止损只决定"亏多少爆", 不决定"是否爆"。

### 永远不要 4：永远不要在单品种上跑（多品种对冲也救不了）

```mql5
// ❌ 错：单品种 XAUUSDm 跑 ScalpingMartin_EA
//   XAUUSDm 2024-10-04 闪崩 200 点, ScalpingMartin_EA 加仓 5 层全爆
```

**根因**：单品种网格马丁 = 把鸡蛋放一个篮子, 篮子一倒全碎。**多品种对冲（一组多 + 一组空）只能在震荡市降低风险, 趋势市两组同时爆**。**反马丁（亏损减仓、盈利加仓）也救不了**——反马丁胜率高但盈亏比差, 一次大亏吃掉前 10 次小赚。**马丁的本质是"赌反转", 没有"安全"变种**。

### 永远不要 5：永远不要把马丁逻辑套到剥头皮 / 高频

```mql5
// ScalpingMartin_EA.mq5 line 8: "高频剥头皮马丁策略, 单日目标5000-10000单"
//   ❌ 错：高频 = 每秒 5+ tick, 马丁加仓 1 秒内触发 3 次
//   → 1 秒内开 3 单 × 0.05 lot = 0.15 lot, 点差 + 滑点立刻 -30 点
//   → 单日目标 5000-10000 单 = 经纪商拒单（限流 10041 / 10032）

// ❌ 反例：ScalpingMartin_EA V1.5 已经有 [F107] 60秒限频 Print 防止诊断刷屏
//   但实际"开仓"没限频, 1 秒仍可加 3 单
```

**根因**：高频 + 马丁 = 风险叠加。**剥头皮每笔赚 5-10 点但加仓一次亏 50 点, 10 次剥头皮赚 100 点, 1 次加仓亏 50 点 = 净值 +50, 但下 1 次加仓可能亏 200 点 = 直接打回原形**。**剥头皮 + 马丁 = 给经纪商送 commission, EA 90% 概率长期亏损**。

### 永远不要 6：永远不要在回测"赚钱"后就上实盘

```mql5
// ❌ 错：Strategy Tester 跑 2024-01 ~ 2024-12, Net Profit +800%, Max DD 12%
//   → 立刻 attach 实盘 → 2025-01 第一周爆仓
//   原因：2024 年是震荡市, 2025-01 黑天鹅单边市, 马丁必爆
```

**根因**：马丁回测的"漂亮曲线" = 100% 过拟合震荡区间。**所有马丁 EA 在 5-10 年区间一定会有 1-2 个"灾难月"——回测看不到的尾部风险**。**正确做法**：
1. 跑 5-10 年回测（不是 1 年）
2. 看 Max DD 的 worst case（不是 average）
3. 做 Walk-Forward：3 个独立区间都通过
4. **实盘必须用 1/10 目标资金 跑 3 个月**
5. 任何"爆仓月"出现立即停 EA

## 3. 5 已知陷阱（具体案例）

### 陷阱 1：等比加仓第 5 层手数爆炸

| 层 | 等比 (r=2) | 等差 (step=0.01) | 斐波那契 |
|---|---|---|---|
| 1 | 0.01 | 0.01 | 0.01 |
| 2 | 0.02 | 0.02 | 0.01 |
| 3 | 0.04 | 0.03 | 0.02 |
| 4 | 0.08 | 0.04 | 0.03 |
| 5 | **0.16** | 0.05 | 0.05 |
| 累计 | **0.31** | 0.15 | 0.12 |
| 第 5 单手数 | 16x 首单 | 5x 首单 | 5x 首单 |
| 单边 200 点亏损 | -620 USD | -300 USD | -240 USD |

**等比 r=2 是最危险**——5 层累计 0.31 lot, 单边 200 点亏 62% 账户。**新手别用 r=2, 用 r=1.5 或者直接等差**。ScalpingMartin_EA 用的等差 (0.01/0.02/0.03/0.05/0.08) 相对安全, 但 5 层后手数差距也达 8x。

### 陷阱 2：GridStep 设太小（频繁加仓吃光 spread）

```mql5
// [[02-完整模板/EA 网格马丁模板]] line 32:
input int    GridStep = 200;            // 加仓间隔（点数）
//   XAUUSDm 默认 200 点 = $2 价差 = 看起来"安全"
//   但 XAUUSDm 1 小时正常波动 100-300 点 → 1 小时开 2 单加仓
//   spread $0.30 + commission $0.07 = $0.37 单边 → 2 单加仓 = $0.74 cost
//   均价止盈 100 点 = $1 盈利 → 净赚 $0.26 单笔

// ❌ 反例：把 GridStep 改 50 点（1 小时开 4 单）
//   cost = 4 × $0.37 = $1.48, 均价止盈仍 100 点 $1 = 净亏 $0.48 单笔
```

**根因**：GridStep 决定加仓频率, 频率高 = commission + spread cost 吃掉盈利。**经验值**：XAUUSDm M15 用 200-300 点, H1 用 500-1000 点, H4 用 1000-2000 点。**GridStep < 100 点的马丁 EA 必亏**。

### 陷阱 3：斐波那契加仓"看起来美"但回测仍爆

斐波那契加仓 1,1,2,3,5,8... 比等比慢, 比等差快, **看起来是"折中"**。但**第 6 层 8x 首单手数, 第 7 层 13x**, 一旦到第 7 层, 单边 200 点 = -800 USD = 80% 账户。**斐波那契的"折中"在第 6 层之后消失, 风险跟等比一样爆**。**马丁没有"安全"变种**。

### 陷阱 4：新闻瞬间连开 3-5 单

```mql5
// ScalpingMartin_EA.mq5 V1.5 (line 107) 的 TODO:
// TODO: 新闻过滤 — 未来版本中实现重要经济数据前后静默期, 需接入经济日历API
//   → V1.5 还没接, 新闻 ±30 min 仍按信号开仓
//   → XAUUSDm 2024-08-02 NFP 1 分钟内 spread 跳 30 → 180 点
//   → ScalpingMartin_EA 1 秒内 tick momentum 触发 3 次加仓
//   → 3 单全部以 spread 180 点成交 = -540 USD 单笔
```

**根因**：马丁 + 新闻 = 灾难。**M17 NewsFilter `IsNearEvent(30, 30, _Symbol)` ±30 min 拦截**必须接, [[01-调用模块/M17 新闻过滤 NewsFilter]] 7 章节 spec 有完整接入方式。

### 陷阱 5：周末跳空 + 周一开盘 5 单全爆

```mql5
// [[02-完整模板/EA 网格马丁模板]] 没接 M19 SessionFilter, 默认 24h 跑
//   XAUUSDm 周五收盘 2950, 周一开盘 2980 (30 点跳空高开)
//   周五累计 5 单均价 2940, 周一开盘 2980 → 全部盈利 40 点 = 均价止盈触发 → 看似好
//   但 XAUUSDm 2024-04-15 周一开盘 2350 → 2300 (伊朗袭击以色列, 50 点跳空低开)
//   周五累计 5 单均价 2350, 周一开盘 2300 → 全部 -50 点 = 全平巨亏
```

**根因**：周末跳空 = 价格 gap 100% 不受 EA 控制。**M19 SessionFilter 周末 BLOCK + 周五收盘前 30 min 全平** 必须接, [[01-调用模块/M19 时段过滤 SessionFilter]] 有完整接入。

## 4. 替代方案（5 个非马丁思路）

> **如果你是新手 / 资金 < 10,000 USD / 风险承受 < 50%**, 强烈建议先学 5 个非马丁思路。马丁放到最后学。

### 4.1 顺势趋势跟踪（MA 交叉 / Donchian 突破）

**思路**：MA 50 / MA 200 金叉做多, 死叉做空, 顺势持仓。**优势**：胜率 40-50% 但盈亏比 2-3x, 长期正期望。**模板**：[[02-完整模板/EA 趋势跟踪模板（MA 交叉）]] + [[02-完整模板/EA 突破模板（Donchian/海龟）]]。**实物**：`MQL5/Experts/_archive/BBTrendEA.mq5`（已复活到 `minimax-ea/BBTrendEA.mq5`）。

### 4.2 逆势均值回归（BB 边界 + RSI 极端）

**思路**：价格触及 BB 上轨 + RSI > 70 做空, 触及 BB 下轨 + RSI < 30 做多, 反向回归。**优势**：震荡市胜率 60-70%, 盈亏比 1.5-2x。**模板**：[[02-完整模板/EA 逆势均值回归模板（RSI Bollinger）]]。**实物**：`MQL5/Experts/minimax-ea/MeanReversion_EA.mq5`（13 模块全集, 沙盒 1 周 30 笔）。

### 4.3 多品种对冲（相关性过滤 + 反向开仓）

**思路**：XAUUSDm + EURUSDm 同向相关性高, 当两者都触发做多信号时, 用 M18 拦截其中一个, 避免双倍暴露。**优势**：多品种分散, Max DD 比单品种低 30-50%。**模板**：[[02-完整模板/EA 多品种对冲模板]] + [[01-调用模块/M18 相关性过滤 CorrelationFilter]]。**实物**：`MQL5/Experts/minimax-ea/MeanReversion_EA.mq5`（4 品种同 EA, M18 threshold=0.7）。

### 4.4 时段过滤（伦敦 + 纽约 14h 覆盖）

**思路**：XAUUSDm 凌晨 3-5 点流动性最低, 全天 24h 跑 = 8 小时"地雷时段"。**M19 SessionFilter** 限制 8-22 UTC (伦敦+纽约) = 跳过 10 小时低流动性。**优势**：胜率提升 10-20%, Max DD 降 20-30%。**模板**：[[01-调用模块/M19 时段过滤 SessionFilter]] 5 方法 4 预定义常量。**实物**：`MeanReversion_EA.mq5` preset="London:8-16,NewYork:13-22"。

### 4.5 仓位管理（Kelly 公式 + 风控分层）

**思路**：每笔风险 = 账户 × 1% (单笔), 总风险 ≤ 6% (6 笔并发), 单日亏损 ≤ 3% (日内清仓)。**M02 Risk + M03 PositionSizing** 封装。**优势**：黑天鹅时单笔最大亏 1%, 不会爆仓。**模板**：[[01-调用模块/M02 风控 Risk]] + [[01-调用模块/M03 仓位计算 PositionSizing]]。**实物**：`MeanReversion_EA.mq5` line 199 `risk.CanOpen` + line 197 `sizing.LotByRisk`。

## 6. 回测 SOP（如果非跑不可）

> **如果真的要回测马丁 EA**（教学目的）, 严格按本 SOP 跑 8 步, 缺一步结论无效。

### 6.1 8 步回测 SOP

| 步骤 | 动作 | 必查项 |
|---|---|---|
| 1 | 数据长度 ≥ **5 年** | MT5 Strategy Tester → "Date" 设 2020-01-01 ~ 2025-01-01 |
| 2 | 模式 = "**1 分钟 OHLC**"（不用 Real Tick, 太慢且马丁对 tick 不敏感）| — |
| 3 | 初始资金 = 10,000 USD（**不要用 1,000 USD**）| — |
| 4 | 跑 2 套参数 baseline + 优化 | baseline = 模板默认, 优化 = `Max_Levels=3/5/7` × `LotMultiplier=1.5/2.0/2.5` |
| 5 | 必看 4 个指标 | Total Trades ≥ 100 / Profit Factor / Max DD / Recovery Factor |
| 6 | **看最差月** | "Graph" → "Balance" → 找最大单月亏损, **Max DD 来自最差月** |
| 7 | **做 Walk-Forward** | 区间 1 (2020-01~06) 找最优 → 区间 2 (2020-07~12) 验证 → 区间 3 (2021-01~06) 再验证 |
| 8 | **黑天鹅压力测试** | 在 2020-03 (COVID 闪崩) / 2022-03 (俄乌) / 2023-03 (SVB) 月份单跑, 看 Max DD |

### 6.2 关键结论判断

- **Total Trades < 100** = 样本不足, 结论无效
- **Max DD > 30%** = 实盘必爆, 弃用
- **Walk-Forward 3 区间全通过** = **可以小资金 1/10 上 demo, 跑 3 个月**
- **3 个月 demo 爆仓 1 次** = 弃用
- **3 个月 demo +3 个月实盘 1/10 资金不爆** = 加仓到 1/3, 再跑 6 个月
- **总计 1 年不爆** = **可以认为是"安全的马丁"**（但仍然 < 5 年存活率 10%）

### 6.3 5 个绝对不能用的回测结论

1. ❌ "1 年回测 Net Profit +200%" — 1 年必过拟合, 看 5 年
2. ❌ "Max DD < 10%" — 多半是 trade count < 30, 不显著
3. ❌ "Sharpe > 2.0" — 马丁天然 Sharpe 高, 但 Max DD 也高
4. ❌ "Profit Factor > 3.0" — 等比马丁天然 PF 高, 单边市破功
5. ❌ "1 个月 demo 不爆 = 安全" — 马丁平均 14 个月才爆, 1 个月看不到
