# 通用片段 - 读取行情/数据

## 读 K 线

### 完整 OHLC

```mql5
MqlRates rates[];
ArraySetAsSeries(rates, true);
int n = CopyRates(_Symbol, _Period, 0, 100, rates);
if (n < 0) {
   Print("CopyRates 失败 err=", GetLastError());
   return;
}
// rates[0] = 当前 K 线（未关闭）
// rates[1] = 上一根
// rates[i] = 倒推 i 根
```

### 单字段

```mql5
double close[];
ArraySetAsSeries(close, true);
CopyClose(_Symbol, _Period, 0, 100, close);
```

### 单独拿一根

```mql5
double c0 = iClose(_Symbol, _Period, 0);
```

**典型代码段 (L253-260 _CheckDrawdown 净值回撤)**:

```mql5
// M10 触发器 1: 净值回撤 > DDAlertPct 报警
void _CheckDrawdown() {
   if (!EnableNotify) return;
   double equity = AccountInfoDouble(ACCOUNT_EQUITY);   // 02 段 2 读账户 (L255)
   if (equity <= 0) return;
   if (equity > _peakEquity) _peakEquity = equity;       // OnInit L101 已记录峰值
   if (_peakEquity <= 0) return;
   double ddPct = (_peakEquity - equity) / _peakEquity * 100.0;
   if (ddPct >= DDAlertPct && !_ddAlertActive) {
      _ddAlertActive = true;
      M10.Send(StringFormat("[DD] %.2f%% on %s (eq=%.2f peak=%.2f)",
                            ddPct, _Symbol, equity, _peakEquity), true);
   } else if (ddPct < DDAlertPct * 0.5) {
      _ddAlertActive = false;
   }
}
```

**典型代码段 (L271-296 OnTrade 历史成交遍历)**:

```mql5
// M10 触发器 2: 新成交通知 (02 段 9-21 集中调用)
void OnTrade() {
   if (!EnableNotify) return;
   if (!HistorySelect(0, TimeCurrent())) return;          // 02 段 9 读时间
   int total = HistoryDealsTotal();                       // 02 段 10
   if (total <= 0) return;
   for (int i = total - 1; i >= 0; i--) {
      ulong ticket = HistoryDealGetTicket(i);             // 02 段 11
      if (ticket == 0) continue;
      if (ticket == _lastDealTicket) break;               // 去重
      if ((ulong)HistoryDealGetInteger(ticket, DEAL_MAGIC) != Magic) continue;  // 02 段 12
      string  symbol = HistoryDealGetString(ticket, DEAL_SYMBOL);   // 02 段 13
      long    dtype  = HistoryDealGetInteger(ticket, DEAL_TYPE);    // 02 段 14
      double  volume = HistoryDealGetDouble (ticket, DEAL_VOLUME);  // 02 段 15
      double  price  = HistoryDealGetDouble (ticket, DEAL_PRICE);   // 02 段 16
      long    entry  = HistoryDealGetInteger(ticket, DEAL_ENTRY);   // 02 段 17
      string  typeStr = (dtype == DEAL_TYPE_BUY)  ? "BUY"
                      : (dtype == DEAL_TYPE_SELL) ? "SELL"
                      : EnumToString((ENUM_DEAL_TYPE)dtype);        // 02 段 18+20
      string entryStr = (entry == DEAL_ENTRY_IN)  ? "OPEN"
                      : (entry == DEAL_ENTRY_OUT) ? "CLOSE"
                      : EnumToString((ENUM_DEAL_ENTRY)entry);       // 02 段 19
      M10.Trade(typeStr + "/" + entryStr, symbol, price, volume, 0, "MeanRev");
   }
   _lastDealTicket = HistoryDealGetTicket(total - 1);    // 02 段 21
}
```

### 陷阱 (5 条, 来自 ScalperXAU + MeanReversion_EA 实测)

1. **HistorySelect 范围不设上限** (ScalperXAU L211/L914/L993, MeanRev L274):
   - 错反例: `HistorySelect(0, TimeCurrent());` — 全量加载, 服务器慢时 10000+ deal 遍历 5s+
   - 对正例: `HistorySelect(TimeCurrent() - PeriodSeconds(PERIOD_D1)*7, TimeCurrent());` — 限定近 7 天, 倒序遍历最多 100-200 deal
   - 根因: 02 wiki "## 必看" 已警示"历史时间范围不要太大", 但 MQL5Kit 0 wrapper 强制, 易漏
   - 修复: 02 段 `HistorySelect(from, to)` 包一层 `SafeHistorySelect(int lookbackDays = 7)`, 见 04 wiki 调优点段

2. **读持仓用 PositionsTotal + Magic 比对, 0 M07 wrapper** (ScalperXAU L566-609):
   - 错反例: `for (i=0; i<PositionsTotal(); i++) { ulong t=PositionGetTicket(i); if (PositionGetInteger(POSITION_MAGIC) != Magic) continue; }` — 每次 OnTick 遍历所有 magic, XAUUSDm 上 broker 通常有 5-10 个其他 EA 的持仓, 浪费 CPU
   - 对正例: `int n = CPositions::CountMine(Magic);` (M07 wrapper 内部已经按 magic 过滤) + `CPositions::HasDirection(Magic, POSITION_TYPE_BUY)` (MeanRev L180 用此)
   - 根因: 02 段 读持仓是"无差别遍历", M07 包装后才是"本 EA 持仓"
   - 修复: 任何"本 EA 持仓"操作改用 M07 wrapper, 02 段保留给"跨 EA 持仓扫描"或调试

3. **CopyBuffer 句柄不释放** (ScalperXAU L348/L496-513 12 处, 0 IndicatorRelease 配对):
   - 错反例: `int h = iMA(_Symbol, _Period, 20, 0, MODE_EMA, PRICE_CLOSE); CopyBuffer(h, 0, 0, 100, buf);` — 句柄 h 后续没 IndicatorRelease, OnDeinit 也没释放
   - 对正例: 用 M04 包装 `ind.AddMA("MA", 20); ind.Value("MA", 0);` (M04 内部句柄管理 + OnDeinit ReleaseAll, MeanRev L214 模式)
   - 根因: 02 wiki "## 读指标值" 第 2 段"用 iMA 简写 (每 tick 都创建句柄, 性能差)" 是同一根因
   - 修复: Scalper 12 处 CopyBuffer 改用 M04 wrapper, 4 处 IndicatorRelease (L1016-1019) 保留作为 OnDeinit 兜底

4. **TimeCurrent(dt) 周末/跨午夜不处理** (ScalperXAU L198/L213/L236/L287/L454/L473, MeanRev L161):
   - 错反例: `MqlDateTime dt; TimeCurrent(dt); if (dt.hour < 8 || dt.hour >= 20) return;` — 自己硬编码时段, 周末 0-23h 都判 false 误杀
   - 对正例: `M19.IsInSession(TimeCurrent())` (MeanRev L161 用此) — M19 内部已经处理周末 (SetAllowWeekend) + 跨午夜 (startHour > endHour), 0 漏判
   - 根因: 02 段 读时间 + MqlDateTime 是"裸字段时间处理", 0 时区/周末/跨午夜处理
   - 修复: 任何"判断是否在交易时段"操作改用 M19 wrapper, 02 段保留给"读时间戳"或"统计当日成交"等无时段需求场景

5. **EnumToString((ENUM_DEAL_TYPE)0) 周末空单返回空串** (MeanRev L289, Scalper L321):
   - 错反例: `string typeStr = EnumToString((ENUM_DEAL_TYPE)dtype);` — 历史 deal 周末/特殊类型可能返回 0, EnumToString(0) 给 "DEAL_TYPE_BUY" 误识别
   - 对正例: `if (dtype < 0 || dtype > DEAL_TYPE_SELL) typeStr = "UNKNOWN(" + IntegerToString(dtype) + ")"; else typeStr = (dtype == DEAL_TYPE_BUY) ? "BUY" : "SELL";` (MeanRev L287-289 模式, 三元运算符替代 EnumToString)
   - 根因: 02 段 读历史成交的 DEAL_TYPE 字段值域未校验, EnumToString 兜底返回可读但可能错
   - 修复: MeanRev L287-289 用三元运算符替代 EnumToString (更安全), Scalper L321 仍用 EnumToString 是历史代码, 1 行正则替换
