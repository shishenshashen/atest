# 通用片段 - 实用函数

## 时间转换

```mql5
// 字符串 → datetime
datetime t = StringToTime("2025.11.04 11:30:00");
datetime t2 = StringToTime("2025.11.04");   // 00:00:00

// datetime → 字符串
string s = TimeToString(t);                  // 2025.11.04 11:30:00
string s2 = TimeToString(t, TIME_DATE);      // 2025.11.04
string s3 = TimeToString(t, TIME_MINUTES);   // 2025.11.04 11:30

// 拆字段
MqlDateTime dt;
TimeToStruct(t, dt);
// dt.year, dt.mon (1-12), dt.day, dt.hour, dt.min, dt.sec
// dt.day_of_week (0=Sun), dt.day_of_year

// 一天的秒数
datetime dayStart = StringToTime(TimeToString(TimeCurrent(), TIME_DATE));

// 月初
MqlDateTime now;
TimeCurrent(now);
datetime monthStart = StringToTime(
   IntegerToString(now.year) + "." +
   IntegerToString(now.mon) + ".01");
```

## 价格规范化

```mql5
// 通用：按品种小数位
double NormalizeMyPrice(double price) {
   return NormalizeDouble(price, _Digits);
}

// 按 tick size 取整
double RoundToTick(double price) {
   double tickSize = SymbolInfoDouble(_Symbol, SYMBOL_TRADE_TICK_SIZE);
   if (tickSize == 0) return price;
   return NormalizeDouble(MathRound(price / tickSize) * tickSize, _Digits);
}
```

## 手数规范化

```mql5
double NormalizeLot(double lot) {
   double minL  = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MIN);
   double maxL  = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_MAX);
   double stepL = SymbolInfoDouble(_Symbol, SYMBOL_VOLUME_STEP);
   if (stepL > 0) lot = MathFloor(lot / stepL) * stepL;
   lot = MathMax(minL, MathMin(maxL, lot));
   return NormalizeDouble(lot, 2);
}
```

## 打印所有持仓

```mql5
void PrintAllPositions() {
   Print("--- 当前持仓 (", PositionsTotal(), ") ---");
   for (int i = PositionsTotal() - 1; i >= 0; i--) {
      ulong t = PositionGetTicket(i);
      if (t == 0) continue;
      if (!PositionSelectByTicket(t)) continue;
      string sym  = PositionGetString(POSITION_SYMBOL);
      long   type = PositionGetInteger(POSITION_TYPE);
      double vol  = PositionGetDouble(POSITION_VOLUME);
      double open = PositionGetDouble(POSITION_PRICE_OPEN);
      double cur  = PositionGetDouble(POSITION_PRICE_CURRENT);
      double sl   = PositionGetDouble(POSITION_SL);
      double tp   = PositionGetDouble(POSITION_TP);
      double prof = PositionGetDouble(POSITION_PROFIT);
      ulong  mag  = (ulong)PositionGetInteger(POSITION_MAGIC);
      string dir  = (type == POSITION_TYPE_BUY) ? "BUY" : "SELL";
      PrintFormat("#%I64u %s %s %.2f @%.5f (cur=%.5f) SL=%.5f TP=%.5f P/L=%.2f magic=%I64u",
                  t, sym, dir, vol, open, cur, sl, tp, prof, mag);
   }
}
```

## 打印所有挂单

```mql5
void PrintAllOrders() {
   Print("--- 当前挂单 (", OrdersTotal(), ") ---");
   for (int i = OrdersTotal() - 1; i >= 0; i--) {
      ulong t = OrderGetTicket(i);
      if (t == 0) continue;
      OrderSelect(t);
      string sym  = OrderGetString(ORDER_SYMBOL);
      long   type = OrderGetInteger(ORDER_TYPE);
      double pr   = OrderGetDouble(ORDER_PRICE_OPEN);
      double vol  = OrderGetDouble(ORDER_VOLUME_INITIAL);
      string typeName = EnumToString((ENUM_ORDER_TYPE)type);
      PrintFormat("#%I64u %s %s %.2f @%.5f", t, sym, typeName, vol, pr);
   }
}
```

## 打印所有全局变量

```mql5
void PrintAllGV(string prefix = "") {
   Print("--- 全局变量 ---");
   int n = GlobalVariablesTotal();
   for (int i = 0; i < n; i++) {
      string name = GlobalVariableName(i);
      if (prefix != "" && StringFind(name, prefix) != 0) continue;
      double val = GlobalVariableGet(name);
      PrintFormat("  %s = %.5f", name, val);
   }
}
```

## 距离上次 X 时间的秒数

```mql5
int SecondsSince(datetime t) {
   return (int)(TimeCurrent() - t);
}
int MinutesSince(datetime t) { return SecondsSince(t) / 60; }
int HoursSince(datetime t)   { return SecondsSince(t) / 3600; }
```

## 判断是否在交易时段

```mql5
bool IsInSession(int startHour, int endHour) {
   MqlDateTime dt;
   TimeCurrent(dt);
   if (startHour < endHour)
      return (dt.hour >= startHour && dt.hour < endHour);
   else  // 跨午夜
      return (dt.hour >= startHour || dt.hour < endHour);
}
```

## 算两值的百分比变化

```mql5
double PctChange(double from, double to) {
   if (from == 0) return 0;
   return (to - from) / from * 100.0;
}
```

## 字符串数组 → 字符串

```mql5
string ArrayToStr(string &arr[], string sep = ",") {
   string out = "";
   for (int i = 0; i < ArraySize(arr); i++) {
      if (i > 0) out += sep;
      out += arr[i];
   }
   return out;
}
```

## 安全的除法

```mql5
double SafeDiv(double a, double b, double def = 0) {
   return (b == 0) ? def : a / b;
}
```

### 陷阱 (5 条, 来自 ScalperXAU + MeanReversion_EA 实测)

1. **GetLastError 裸打数字不友好** (ScalperXAU L645):
   - ❌ 反例: `Print("v4 debug FileOpen fail err=", GetLastError());` — 打 raw 数字 5004, 用户不知"文件句柄无效"
   - ✅ 正例: `int err = GetLastError(); PrintFormat("FileOpen 失败: %s (%d)", ErrorText(err), err); ResetLastError();` — ErrorText 转中文 + raw 数字, 跟 04 实用函数用法示例对齐
   - 修复: 全 EA 搜 `GetLastError` 替换为 ErrorText (1 行正则替换)

2. **NormalizeDouble SL 后忘二次校验 MinStopLevel** (ScalperXAU L756):
   - ❌ 反例: `double slPrice = NormalizeDouble(slRaw, _Digits);` — 仅规范化小数位, 没检查 broker 最小止损距离 → 拒单 ERR 130
   - ✅ 正例: 加 `M02.Risk.CheckMinStopLevel(_Symbol, price, slPrice)` 二次校验 (M02 内部调 SymbolInfoInteger(SYMBOL_TRADE_STOPS_LEVEL))
   - 根因: `_Digits` 只管小数位, 不管 broker 要求的"价格距离"; MinStopLevel 是 broker-level 规则

3. **TimeCurrent(dt) 周末/跨午夜不处理** (ScalperXAU L198/213/236, MeanRev L161):
   - ❌ 反例: 裸 `TimeCurrent(dt); if (dt.hour < 8 || dt.hour >= 20) return;` — 自己硬编码时段, 周末 0-23h 都判 false 误杀
   - ✅ 正例: 调 `M19.IsInSession(TimeCurrent())` (MeanRev L161) — M19 内部已经处理周末 (SetAllowWeekend) + 跨午夜 (startHour > endHour), 0 漏判
   - 04 实用函数的 IsInSession (L139-146) 周末一律 return false, 周末如果想跑需要单独加判断

4. **PrintAllPositions / PrintAllOrders 量产卡 IO** (04 函数 L70-89, 95-108):
   - ❌ 反例: OnTick 顶部调 PrintAllPositions() — 每 tick 打印 5-10 持仓 + 5-10 挂单, 1 小时 3600 次 print, Journal 卡死
   - ✅ 正例: 用 M07.Positions 替代 + M11.Logger.Info() — M07 自带去重 (同 ticket 不重复打), M11 带 timestamp
   - 04 实用函数 PrintAllPositions 是 debug 期工具, 生产 EA 必替换

5. **EnumToString((ENUM_DEAL_TYPE)0) 周末空单返回空串** (MeanRev L289, Scalper L321):
   - ❌ 反例: `string typeStr = EnumToString((ENUM_DEAL_TYPE)dtype);` — 历史 deal 周末/特殊类型可能返回 0, EnumToString(0) 返 "DEAL_TYPE_BUY" 误识别
   - ✅ 正例: 加 `if (dtype < 0 \|\| dtype > DEAL_TYPE_SELL) typeStr = "UNKNOWN(" + IntegerToString(dtype) + ")";`
   - 04 实用函数无此防护, ErrorText 同样有 case 未覆盖返"错误代码 N"问题 (L214) — 防御性补 default 分支
