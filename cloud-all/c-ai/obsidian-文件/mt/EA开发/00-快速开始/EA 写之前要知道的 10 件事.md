# EA 写之前要知道的 10 件事

> 写之前看完能少走 80% 弯路。

## 1. MT5 的"持仓"和"挂单"是两套系统
- 持仓：`PositionsTotal()` / `PositionGetXxx()` — 实际仓位
- 挂单：`OrdersTotal()` / `OrderGetXxx()` — 未触发的条件单
- 成交记录：`HistorySelect()` + `HistoryDealsTotal()` — 历史
- **平仓用 `PositionClose`，删挂单用 `OrderDelete`**

## 2. OrderSend 的两个返回值
- `OrderSend` 返回 `true` ≠ 成交成功
- 必须再检查 `result.retcode == TRADE_RETCODE_DONE`
- 完整的失败处理见 [[01-调用模块/M01 交易封装 CTradePlus]]

## 3. type_filling 必须正确
- 外汇: FOK / IOC 二选一
- 股票/期货: RETURN
- 用 `SymbolInfoInteger(_Symbol, SYMBOL_FILLING_MODE)` 查

## 4. 倒序数组的坑
- 99% EA 都需要 `ArraySetAsSeries(buf, true); CopyXxx(...);`
- 不加这一行，`[0]` 是 30 年前的 K 线
- 见 [[04-避坑与速查/01 编译常见错误]]

## 5. magic + comment 隔离多策略
- 同一账户跑多个 EA → 每个 EA 用**不同 magic**
- `OrderSend` / `PositionGet` 全部按 magic 过滤
- 不然后期 EA 之间会互相乱开乱平

## 6. 必须做的风控（**直接抄** [[01-调用模块/M02 风控 Risk]]）
- 下单前查：手数范围、保证金够、最小止损距离、最大持仓数
- 浮亏过大 → 自动全平
- 一笔单的最大亏损 ≤ 账户净值的 1-2%

## 7. 浮点 + 价格规范化
- 任何价格计算结果都要 `NormalizeDouble(price, _Digits)`
- 不然 `OrderSend` 会因价格小数位不对被拒

## 8. 报错一定要看
- `GetLastError()` 和 `result.retcode` 是两个错误
- Print 出来是排错第一手段

## 9. 模拟账户先跑 1-2 周
- 回测 ≠ 实盘
- 滑点、点差、跳空、服务器维护都只能实盘暴露

## 10. 别在 OnTick 里重计算
- 指标用 `iMA/iRSI/iATR` 句柄，**不要每 tick 重新算**
- 长期运行考虑用 OnTimer（100ms 一次）轮询
