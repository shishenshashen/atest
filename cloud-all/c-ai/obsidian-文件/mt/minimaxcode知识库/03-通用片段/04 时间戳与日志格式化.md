# 04 时间戳与日志格式化

> 跨任务复用：时间戳生成、ISO 8601、UTC 转换、可读时长、统一日志行格式。

## 时间戳基础

```powershell
# 当前本地时间
Get-Date
# 2026-06-03 11:58:19

# 当前 UTC
(Get-Date).ToUniversalTime()
# 2026-06-03 03:58:19

# 各种格式
Get-Date -Format "yyyy-MM-dd"           # 2026-06-03
Get-Date -Format "yyyy-MM-dd HH:mm:ss"  # 2026-06-03 11:58:19
Get-Date -Format "yyyyMMdd_HHmmss"      # 20260603_115819  (用于文件名)
Get-Date -Format "o"                    # 2026-06-03T11:58:19.1234567+08:00  (round-trip)
Get-Date -Format "s"                    # 2026-06-03T11:58:19  (ISO 8601, sort-friendly)
Get-Date -Format "u"                    # 2026-06-03 03:58:19Z (UTC, sort-friendly)
Get-Date -Format "yyyy-MM-ddTHH:mm:ssZ" # 自定义 ISO 8601 with Z
```

## ISO 8601 标准输出（推荐）

```powershell
# 本地时区 + 偏移
$isoLocal = (Get-Date).ToString("yyyy-MM-ddTHH:mm:sszzz")
# 2026-06-03T11:58:19+08:00

# UTC 强制带 Z
$isoUtc = (Get-Date).ToUniversalTime().ToString("yyyy-MM-ddTHH:mm:ssZ")
# 2026-06-03T03:58:19Z

# 毫秒精度（脚本里排查时序问题用）
$isoMs = (Get-Date).ToString("yyyy-MM-ddTHH:mm:ss.fffzzz")
# 2026-06-03T11:58:19.123+08:00
```

## Unix 时间戳

```powershell
# 当前 → Unix 秒
$unixSec = [int][double]::Parse((Get-Date -UFormat %s))
# 或
$unixSec = [int]((Get-Date).ToUniversalTime() - [DateTime]'1970-01-01').TotalSeconds

# Unix 毫秒（JavaScript / Go 常用）
$unixMs = [long]((Get-Date -Date ((Get-Date).ToUniversalTime()) `
  -UFormat %s) * 1000)

# Unix → DateTime
$dt = (Get-Date "1970-01-01").AddSeconds(1717384699)
$dt.ToLocalTime()
```

## 日志行：统一格式函数

```powershell
function Write-Log {
  param(
    [ValidateSet("DEBUG","INFO","WARN","ERROR","FATAL")]
    [string]$Level = "INFO",
    [string]$Message,
    [string]$LogFile = "C:\Users\Administrator\.mavis\logs\app.log"
  )

  $ts = (Get-Date).ToString("yyyy-MM-ddTHH:mm:ss.fffzzz")
  $pid = $PID
  $line = "$ts [$Level] [pid=$pid] $Message"

  # 控制台彩色
  $color = switch ($Level) {
    "DEBUG" { "Gray" }
    "INFO"  { "White" }
    "WARN"  { "Yellow" }
    "ERROR" { "Red" }
    "FATAL" { "Magenta" }
  }
  Write-Host $line -ForegroundColor $color

  # 文件：始终追加（解决并发写问题）
  Add-Content -Path $LogFile -Value $line -Encoding UTF8
}
```

## 可读时长（"1h 23m 45s"）

```powershell
function Format-Duration {
  param([TimeSpan]$Span)
  if ($Span.TotalSeconds -lt 1) {
    return "$($Span.TotalMilliseconds.ToString('N0'))ms"
  }
  if ($Span.TotalMinutes -lt 1) {
    return "$($Span.TotalSeconds.ToString('N1'))s"
  }
  if ($Span.TotalHours -lt 1) {
    return "$([int]$Span.TotalMinutes)m $($Span.Seconds)s"
  }
  if ($Span.TotalDays -lt 1) {
    return "$([int]$Span.TotalHours)h $($Span.Minutes)m"
  }
  return "$([int]$Span.TotalDays)d $($Span.Hours)h"
}

Format-Duration (New-TimeSpan -Seconds 45)
# 45.0s
Format-Duration (New-TimeSpan -Minutes 23)
# 23m 0s
Format-Duration (New-TimeSpan -Hours 1 -Minutes 23)
# 1h 23m
Format-Duration (New-TimeSpan -Days 2 -Hours 5)
# 2d 5h
```

## 时区处理

```powershell
# 当前时区
[System.TimeZoneInfo]::Local.Id
# "Asia/Shanghai"

# 列所有时区
[System.TimeZoneInfo]::GetSystemTimeZones() |
  Where-Object { $_.Id -match "Shanghai|Asia/" } |
  Select-Object Id, DisplayName, BaseUtcOffset

# 转到指定时区
function ConvertTo-TimeZone {
  param([DateTime]$DateTime, [string]$TimeZoneId)
  $tz = [System.TimeZoneInfo]::FindSystemTimeZoneById($TimeZoneId)
  return [System.TimeZoneInfo]::ConvertTime($DateTime, $tz)
}

ConvertTo-TimeZone (Get-Date).ToUniversalTime() "Asia/Shanghai"

# 时间戳带时区
$ny = [System.TimeZoneInfo]::FindSystemTimeZoneById("America/New_York")
$now = [System.TimeZoneInfo]::ConvertTime((Get-Date).ToUniversalTime(), [System.TimeZoneInfo]::Utc, $ny)
$now.ToString("yyyy-MM-dd HH:mm:ss zzz")
# 2026-06-02 23:58:19 -04:00
```

## 时间差（"3 分钟前"）

```powershell
function Format-RelativeTime {
  param([DateTime]$Past)
  $span = (Get-Date) - $Past
  $future = $span.TotalSeconds -lt 0
  $span = $span.Duration()

  if ($span.TotalSeconds -lt 60) { $s = "$([int]$span.TotalSeconds) 秒"; }
  elseif ($span.TotalMinutes -lt 60) { $s = "$([int]$span.TotalMinutes) 分钟"; }
  elseif ($span.TotalHours   -lt 24) { $s = "$([int]$span.TotalHours) 小时"; }
  elseif ($span.TotalDays    -lt 30) { $s = "$([int]$span.TotalDays) 天";   }
  elseif ($span.TotalDays    -lt 365){ $s = "$([int]($span.TotalDays/30)) 个月"; }
  else { $s = "$([int]($span.TotalDays/365)) 年"; }

  if ($future) { return "${s}后" } else { return "${s}前" }
}

Format-RelativeTime (Get-Date).AddMinutes(-3)
# 3 分钟前
Format-RelativeTime (Get-Date).AddDays(-2)
# 2 天前
```

## 并发安全：日志锁

```powershell
# 多进程同时写一个文件 → 用 mutex
$logMutex = New-Object System.Threading.Mutex($false, "Global\mavis-app-log")

function Write-LogSafe {
  param([string]$Line, [string]$LogFile)
  $logMutex.WaitOne() | Out-Null
  try {
    Add-Content -Path $LogFile -Value $Line -Encoding UTF8
  } finally {
    $logMutex.ReleaseMutex()
  }
}
```

## 必避的坑

- **Get-Date -Format "o" 返回的字符串含 `+08:00`**，但 `DateTime.Parse` 读它时**本地化为服务器时区**——`ToUniversalTime()` 后才能确保 UTC
- **`[DateTime]::Now` vs `Get-Date`**：基本一样，但 `Get-Date` 在 pipeline 里行为更友好
- **闰秒**：.NET 不处理（业界普遍不处理），可以忽略
- **夏令时**：用 `TimeZoneInfo` 而不是固定 offset 即可
