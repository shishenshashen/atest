# 03 进程与服务管理

> 跨任务复用：找进程、看端口、启停服务、查谁占着资源。

## 查端口谁在占用

```powershell
# 15321 是 mavis daemon 默认端口
function Get-PortOwner {
  param([int]$Port)
  $conn = Get-NetTCPConnection -LocalPort $Port -State Listen -ErrorAction SilentlyContinue
  if (-not $conn) { return $null }
  $procId = $conn.OwningProcess
  $proc = Get-Process -Id $procId -ErrorAction SilentlyContinue
  return [PSCustomObject]@{
    Port    = $Port
    PID     = $procId
    Process = $proc.ProcessName
    Path    = $proc.Path
  }
}

Get-PortOwner 15321
# Port   PID Process  Path
# ----   --- -------  ----
# 15321  4520 mavis   C:\Program Files\mavis\mavis.exe
```

## 找进程（含子进程）

```powershell
function Get-ProcessTree {
  param([string]$Name)
  $root = Get-Process -Name $Name -ErrorAction SilentlyContinue
  if (-not $root) { return @() }
  $all = @($root)
  foreach ($p in $root) {
    $children = Get-CimInstance Win32_Process -Filter "ParentProcessId=$($p.Id)"
    $all += $children | ForEach-Object { Get-Process -Id $_.ProcessId -ErrorAction SilentlyContinue }
  }
  return $all | Where-Object { $_ } | Select-Object Id, ProcessName, StartTime, Path
}

Get-ProcessTree "mavis"
```

## 优雅停进程（先 SIGTERM，再 KILL）

```powershell
function Stop-ProcessGracefully {
  param(
    [string]$Name,
    [int]$TimeoutSec = 10
  )
  $procs = Get-Process -Name $Name -ErrorAction SilentlyContinue
  if (-not $procs) { return $true }

  foreach ($p in $procs) {
    Write-Host "stopping $Name (PID=$($p.Id))..."
    $p.CloseMainWindow() | Out-Null   # 1. 窗口消息（GUI 程序）
    Start-Sleep -Milliseconds 500
  }

  # 2. 等优雅退出
  $deadline = (Get-Date).AddSeconds($TimeoutSec)
  while ((Get-Date) -lt $deadline) {
    $left = Get-Process -Name $Name -ErrorAction SilentlyContinue
    if (-not $left) { return $true }
    Start-Sleep -Milliseconds 500
  }

  # 3. 强 kill
  Write-Host "force killing remaining $Name"
  Stop-Process -Name $Name -Force -ErrorAction SilentlyContinue
  Start-Sleep -Milliseconds 500

  # 4. 验证
  $still = Get-Process -Name $Name -ErrorAction SilentlyContinue
  return -not $still
}
```

## 启动并验证（自愈模式）

```powershell
function Start-AndWait {
  param(
    [string]$Name,
    [string]$Path,
    [int]$ReadyTimeoutSec = 30
  )
  if (Get-Process -Name $Name -ErrorAction SilentlyContinue) {
    Write-Host "$Name already running"
    return $true
  }

  Write-Host "starting $Name..."
  Start-Process -FilePath $Path -WindowStyle Hidden

  $deadline = (Get-Date).AddSeconds($ReadyTimeoutSec)
  while ((Get-Date) -lt $deadline) {
    if (Get-Process -Name $Name -ErrorAction SilentlyContinue) {
      Write-Host "$Name started"
      return $true
    }
    Start-Sleep -Milliseconds 500
  }

  Write-Error "$Name failed to start in ${ReadyTimeoutSec}s"
  return $false
}
```

## 把任意脚本装成服务（NSSM 方案）

> 不想写 C# 又想要"开机自启 + 自愈 + 看得到"——用 NSSM 包装 PowerShell。

```powershell
# 1. 下载 NSSM: https://nssm.cc/download
#    解压到 C:\bin\nssm.exe

# 2. 安装服务
& "C:\bin\nssm.exe" install MavisHealthCheck `
  "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" `
  '-NoProfile -ExecutionPolicy Bypass -File "C:\Users\Administrator\.mavis\bin\mavis-healthcheck.ps1"'

# 3. 配自愈（崩溃自动重启）
& "C:\bin\nssm.exe" set MavisHealthCheck AppRestartDelay 5000
& "C:\bin\nssm.exe" set MavisHealthCheck AppStdout "C:\Users\Administrator\.mavis\logs\healthcheck-stdout.log"
& "C:\bin\nssm.exe" set MavisHealthCheck AppStderr "C:\Users\Administrator\.mavis\logs\healthcheck-stderr.log"
& "C:\bin\nssm.exe" set MavisHealthCheck AppRotateFiles 1
& "C:\bin\nssm.exe" set MavisHealthCheck AppRotateBytes 10485760

# 4. 启动
& "C:\bin\nssm.exe" start MavisHealthCheck

# 5. 验证
Get-Service MavisHealthCheck
```

> NSSM 优势：自带日志、stdout/stderr 分开、文件轮转、崩溃重试。
> 比 schtasks + powershell.exe 更适合"长驻"类脚本。

## 自检：进程 + 端口 + 可达性 三件套

```powershell
function Test-Service {
  param(
    [string]$Name,
    [int]$Port,
    [string]$HealthUrl
  )

  $result = [PSCustomObject]@{
    Name    = $Name
    Process = $false
    Port    = $false
    HTTP    = $false
  }

  $result.Process = [bool](Get-Process -Name $Name -ErrorAction SilentlyContinue)

  if ($Port) {
    $tcp = New-Object System.Net.Sockets.TcpClient
    $iar = $tcp.BeginConnect("localhost", $Port, $null, $null)
    $result.Port = $iar.AsyncWaitHandle.WaitOne(2000, $false)
    if ($result.Port) { $tcp.EndConnect($iar) }
    $tcp.Close()
  }

  if ($HealthUrl) {
    try {
      $r = Invoke-WebRequest -Uri $HealthUrl -UseBasicParsing -TimeoutSec 3
      $result.HTTP = ($r.StatusCode -lt 500)
    } catch { $result.HTTP = $false }
  }

  return $result
}

# 用法
Test-Service -Name mavis -Port 15321 -HealthUrl "http://localhost:15321/mavis/health"
```

## 性能 / 资源快查

```powershell
# 看 mavis 占的 CPU / 内存
Get-Process mavis | Select-Object Id, ProcessName, CPU, WS, StartTime,
  @{n="MemMB";e={[math]::Round($_.WS/1MB,1)}}

# 看所有进程按内存排序
Get-Process | Sort-Object WS -Descending | Select-Object -First 10
  ProcessName, Id, @{n="MemMB";e={[math]::Round($_.WS/1MB,1)}},
  @{n="CPU_sec";e={[math]::Round($_.CPU,1)}}

# 看磁盘占用
Get-PSDrive C | Select-Object Used, Free, @{n="UsedGB";e={[math]::Round($_.Used/1GB,1)}}
```

## 必避的坑

- **`Get-Process` 找不到名字带 `.exe` 的** → 用 `Get-Process -Name xxx`，不要 `Get-Process -Name xxx.exe`
- **`Stop-Process -Force` 丢数据** → 优先用 `Stop-ProcessGracefully`（先 CloseMainWindow 等）
- **服务改 binPath 立即生效** → 不用重启服务管理器，但**要重启服务本身**
- **NSSM 安装后服务"启动"但啥都没跑** → 检查 `AppStdout` 日志，多半是参数路径引号问题
