# 01 CU 相关踩坑

> 来源：agent memory（`~/.mavis/agents/mavis/memory/MEMORY.md`），已验证。

## P-01 CU 被 renderer 自动关闭

**症状**：打开 CU 几秒到几分钟，自动变回 disabled。`GET /mavis/api/cu/enabled` 返 `false`。

**根因**：Mavis CU 渲染器在检测到任何窗口"最小化 / 恢复"事件时，自动 PUT `enabled=false`（reason="disabled by user"）。

**日志**（daemon 端可见）：

```
[cu] enabled changed: true -> false
```

**修复**：keep-alive 脚本每 30s PUT 一次 `enabled=true`。

→ 完整脚本见 [[02-实战模板/T01 CU keep-alive 守护脚本]]
→ 注册开机自启见 [[02-实战模板/T02 开机自启计划任务]]

## P-02 配置改了但内存没翻

**症状**：

```powershell
mavis config set beta.cuMode true
# 但 CU 还是关的
```

**根因**：CU 状态有 2 处：

1. **持久化配置**：`beta.cuMode`（写盘）—— 改它不会立即生效
2. **运行时内存**：daemon 进程里的 `cu.enabled` —— 改配置不会立即翻它

**修复**：除了 `config set`，**还必须** PUT API：

```powershell
Invoke-WebRequest -Method PUT `
  http://localhost:15321/mavis/api/cu/enabled `
  -Body '{"enabled":true,"workspaceDir":"C:\Users\Administrator\.mavis\sessions"}' `
  -ContentType "application/json"
```

> 路径前缀是 `/mavis/`（**不是** `/api/`）。

## P-03 RDP session 截屏失败

**症状**：

```
desktop_screenshot: Failed to capture screen
desktop_zoom: Failed to capture screen
desktop_screenshot_region: Failed to capture screen
```

**根因**：`desktop_screenshot` / `desktop_zoom` / `desktop_screenshot_region` 走 nut.js native binding，**RDP session（session 2+）不支持 native 截屏**。

**验证**：

```powershell
# 看当前 session
qwinsta
# 看是不是 RDP
$session = (Get-Process -Id $PID).SessionId
Write-Host "Session ID: $session"
# SessionId > 1 = RDP
```

**修复**：

- **退出 RDP，回到本地 console session（session 1）** 登录
- 临时方案：`desktop_window_list` 不受影响，可以先"侦察"窗口布局
- 长期方案：用 console session 跑 keep-alive（`SYSTEM` 身份在 session 0 跑不了 CU）

## P-04 `desktop_window_list` 行为正常 ≠ 截屏正常

**症状**：看到 `desktop_window_list` 返回正常窗口列表，就以为 CU 工作正常。

**根因**：它走不同 API 路径（不依赖 native binding）。

**检查**：永远以**真实截屏**成功作为"CU 工作"标志。

## P-05 工作目录没指定

**症状**：

```powershell
Invoke-WebRequest -Method PUT http://localhost:15321/mavis/api/cu/enabled `
  -Body '{"enabled":true}'  # 缺 workspaceDir
```

daemon 接受，但后续 session 找不到默认 workspace。

**修复**：永远带 `workspaceDir`：

```powershell
$body = @{
  enabled      = $true
  workspaceDir = "C:\Users\Administrator\.mavis\sessions"
} | ConvertTo-Json -Compress
```

## P-06 `Invoke-WebRequest` 路径里中文 / 空格

**症状**：路径含中文或空格，daemon 收到 400。

**修复**：hashtable body 自动 URL encode；如手动拼接，URI 整体用 `[uri]::EscapeDataString`。

## P-07 多 daemon 端口冲突

**症状**：本机有多个 mavis 实例（开发/生产），端口冲突。

**修复**：自定义端口用环境变量 `MAVIS_PORT`，所有调用走统一客户端函数。
