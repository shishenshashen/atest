# T06 配置文件加载器

## 场景

脚本需要读配置：

- 有则用配置，**没则用默认值**
- 配置文件可能缺字段、字段类型错、值越界 → 要校验 + 报错
- 配置文件可能在多路径（用户目录 / 脚本目录 / 环境变量指定）
- 写配置文件时**不要 BOM**、**不要丢反斜杠**、**不要丢中文**

## 文件

保存为 `C:\Users\Administrator\.mavis\bin\Get-MavisConfig.ps1`：

```powershell
<#
.SYNOPSIS
  带默认值 + 校验 + 多路径的 JSON 配置文件加载器
.PARAMETER Name
  配置文件名（不含扩展名），如 "mavis-watch"
.PARAMETER Default
  默认配置 hashtable
.PARAMETER Schema
  校验规则：@{ field = @{ type = "string|int|bool|array"; required = $true; pattern = "..." } }
#>

function Get-MavisConfig {
  [CmdletBinding()]
  param(
    [Parameter(Mandatory)] [string]$Name,
    [hashtable]$Default = @{},
    [hashtable]$Schema = @{}
  )

  # 多路径查找顺序
  $candidates = @(
    (Join-Path $PSScriptRoot "$Name.json"),                  # 脚本同目录
    (Join-Path $env:USERPROFILE ".mavis\config\$Name.json"), # 用户配置目录
    (Join-Path $env:USERPROFILE ".mavis\$Name.json"),        # 用户 home
    "$env:MAVIS_CONFIG_DIR\$Name.json"                       # 环境变量指定
  ) | Where-Object { $_ -and (Test-Path $_) }

  $loaded = $null
  $source = $null

  if ($candidates.Count -gt 0) {
    $source = $candidates[0]
    try {
      # 强制 UTF-8 无 BOM
      $text = [System.IO.File]::ReadAllText($source)
      if ($text.Length -gt 0) {
        $loaded = $text | ConvertFrom-Json -AsHashtable
      }
    } catch {
      throw "Config parse failed [$source]: $($_.Exception.Message)"
    }
  }

  # 合并：默认 < 文件
  $cfg = $Default.Clone()
  if ($loaded) {
    foreach ($k in $loaded.Keys) {
      $cfg[$k] = $loaded[$k]
    }
  }

  # 校验
  if ($Schema.Count -gt 0) {
    $errors = @()
    foreach ($fieldName in $Schema.Keys) {
      $rule = $Schema[$fieldName]
      $hasValue = $cfg.ContainsKey($fieldName) -and $null -ne $cfg[$fieldName]

      if ($rule.required -and -not $hasValue) {
        $errors += "field '$fieldName' is required"
        continue
      }
      if (-not $hasValue) { continue }

      $v = $cfg[$fieldName]
      $t = if ($rule.type) { $rule.type } else { "any" }

      $ok = switch ($t) {
        "string" { $v -is [string] }
        "int"    { $v -is [int] -or $v -is [long] }
        "number" { $v -is [int] -or $v -is [long] -or $v -is [double] }
        "bool"   { $v -is [bool] }
        "array"  { @($v).Count -gt 0 -or $v -is [array] }
        "object" { $v -is [hashtable] -or $v -is [pscustomobject] }
        "any"    { $true }
        default  { $true }
      }

      if (-not $ok) {
        $errors += "field '$fieldName' must be $t, got $($v.GetType().Name)"
        continue
      }

      if ($rule.pattern -and $v -notmatch $rule.pattern) {
        $errors += "field '$fieldName' does not match pattern: $($rule.pattern)"
      }

      if ($rule.min -and $v -lt $rule.min) {
        $errors += "field '$fieldName' ($v) below min ($($rule.min))"
      }
      if ($rule.max -and $v -gt $rule.max) {
        $errors += "field '$fieldName' ($v) above max ($($rule.max))"
      }

      if ($rule.enum -and $rule.enum -notcontains $v) {
        $errors += "field '$fieldName' ($v) not in enum: [$($rule.enum -join ',')]"
      }
    }

    if ($errors.Count -gt 0) {
      throw "Config validation failed:" + ($errors | ForEach-Object { "`n  - $_" }) `
        -join ""
    }
  }

  # 元数据
  $cfg["_source"] = if ($source) { $source } else { "<default>" }
  return $cfg
}
```

## 使用示例

```powershell
. "C:\Users\Administrator\.mavis\bin\Get-MavisConfig.ps1"

$defaultCfg = @{
  intervalSec = 30
  workspace   = "C:\Users\Administrator\.mavis\sessions"
  enableCU    = $true
  feishuHook  = $null
  logLevel    = "info"
  retryPolicy = @{
    maxAttempts = 3
    backoffSec  = 5
  }
  tags        = @("prod", "auto")
}

$schema = @{
  intervalSec = @{ type = "int";    required = $true; min = 5; max = 3600 }
  workspace   = @{ type = "string"; required = $true; pattern = "^[A-Z]:" }
  enableCU    = @{ type = "bool";   required = $false }
  feishuHook  = @{ type = "string"; required = $false; pattern = "^https://" }
  logLevel    = @{ type = "string"; enum = "debug", "info", "warn", "error" }
  retryPolicy = @{ type = "object" }
  tags        = @{ type = "array" }
}

try {
  $cfg = Get-MavisConfig -Name "mavis-watch" -Default $defaultCfg -Schema $schema
  Write-Host "loaded from: $($cfg._source)"
  Write-Host "intervalSec: $($cfg.intervalSec)"
  Write-Host "logLevel: $($cfg.logLevel)"
} catch {
  Write-Error $_
  exit 1
}
```

## 写配置文件（无 BOM、安全 JSON）

```powershell
function Save-MavisConfig {
  param(
    [string]$Name,
    [hashtable]$Data
  )
  $path = Join-Path $env:USERPROFILE ".mavis\config\$Name.json"
  $dir = Split-Path $path -Parent
  if (-not (Test-Path $dir)) {
    New-Item -ItemType Directory -Force -Path $dir | Out-Null
  }
  # 关键：hashtable + ConvertTo-Json -Compress + .NET 无 BOM
  $json = $Data | ConvertTo-Json -Compress -Depth 10
  [System.IO.File]::WriteAllText(
    $path, $json, [System.Text.UTF8Encoding]::new($false)
  )
  Write-Host "saved: $path"
}

# 用法
Save-MavisConfig "mavis-watch" @{
  intervalSec = 60
  logLevel    = "debug"
  tags        = @("test")
}
```

## 支持 YAML（可选）

PowerShell 5.1 没有原生 YAML 解析。两种方案：

### 方案 A：用 yq.exe（外部二进制）

```powershell
# 下载 yq: https://github.com/mikefarah/yq/releases
$yq = "C:\bin\yq.exe"
$obj = & $yq eval -o=json '.' "config.yaml" | ConvertFrom-Json
```

### 方案 B：用 PowerShell-Yaml 模块

```powershell
Install-Module -Name powershell-yaml -Scope CurrentUser
Import-Module powershell-yaml
$obj = Get-Content "config.yaml" -Raw | ConvertFrom-Yaml
```

## 配置目录约定

```
~/.mavis/
├── config/
│   ├── mavis-watch.json      # 各脚本的配置
│   ├── mavis-watch.dev.json  # 开发环境（NAME.dev.json 覆盖主配置）
│   └── ...
├── logs/                     # 日志（不放在 config）
└── ...
```

> **dev 覆盖** 模式：脚本里优先找 `mavis-watch.dev.json`，找不到再找 `mavis-watch.json`。配合 `Get-MavisConfig` 用 `candidates` 顺序实现。

## 必避的坑

### ❌ 字符串拼接构造 JSON

```powershell
# 错：丢反斜杠 / 中文乱码
$cfg = '{"workspace":"' + $workspace + '","enabled":true}'
```

### ❌ 不用 `AsHashtable`

```powershell
# 错：ConvertFrom-Json 默认是 PSCustomObject，键访问用 .k
$cfg = Get-Content "config.json" | ConvertFrom-Json
$cfg.intervalSec  # ok
$cfg["intervalSec"]  # 错！

# 对：
$cfg = Get-Content "config.json" -Raw | ConvertFrom-Json -AsHashtable
$cfg["intervalSec"]  # ok
```

### ❌ 不校验就信配置

```powershell
# 错：配置文件里 "intervalSec": "30"（字符串不是 int）
Start-Sleep -Seconds $cfg.intervalSec
# 抛 "Cannot convert ..." 

# 对：用上面的 schema 校验，类型不对直接启动失败
```

### ❌ 默认值嵌套对象共享引用

```powershell
# 错：所有调用共享同一 hashtable
$default = @{ retry = @{ max = 3 } }
$cfg = $default.Clone()  # 浅克隆
$cfg.retry.max = 99      # 改了 $default.retry.max！

# 对：深度克隆
function DeepClone($o) {
  if ($o -is [hashtable]) {
    $h = @{}
    foreach ($k in $o.Keys) { $h[$k] = DeepClone $o[$k] }
    return $h
  } elseif ($o -is [array]) {
    return @($o | ForEach-Object { DeepClone $_ })
  } else { return $o }
}
```

## 调试技巧

```powershell
# 看配置实际从哪加载
$cfg = Get-MavisConfig -Name "mavis-watch" -Default $defaultCfg
Write-Host "config source: $($cfg._source)"

# 校验失败时打印完整对象
$cfg = $defaultCfg.Clone()
$cfg["intervalSec"] = "wrong"  # 故意错
try {
  $cfg = Get-MavisConfig -Name "mavis-watch" -Default $cfg -Schema $schema
} catch {
  Write-Host $_.Exception.Message
  Write-Host "default was: $($cfg | ConvertTo-Json -Depth 3)"
}
```
