# T05 日志轮转守护

## 场景

keep-alive、healthcheck、agent 输出都会写日志。**不轮转 = 几个月后磁盘撑爆**。

## 文件

保存为 `C:\Users\Administrator\.mavis\bin\logrotate.ps1`：

```powershell
<#
.SYNOPSIS
  通用日志轮转器
.PARAMETER LogDir
  监控的目录（默认 ~/.mavis/logs）
.PARAMETER MaxSizeMB
  单文件超过此大小则轮转（默认 50 MB）
.PARAMETER KeepCount
  保留的历史文件数（默认 10）
.PARAMETER CompressOld
  是否把旧文件用 gzip 压缩（默认 $true）
#>

param(
  [string]$LogDir = "C:\Users\Administrator\.mavis\logs",
  [int]$MaxSizeMB = 50,
  [int]$KeepCount = 10,
  [bool]$CompressOld = $true
)

$ErrorActionPreference = "Stop"
$BytesLimit = $MaxSizeMB * 1MB

if (-not (Test-Path $LogDir)) {
  Write-Host "log dir not found: $LogDir" -ForegroundColor Yellow
  exit 0
}

function Format-Size([long]$bytes) {
  if ($bytes -ge 1GB) { return "{0:N1} GB" -f ($bytes / 1GB) }
  if ($bytes -ge 1MB) { return "{0:N1} MB" -f ($bytes / 1MB) }
  if ($bytes -ge 1KB) { return "{0:N1} KB" -f ($bytes / 1KB) }
  return "$bytes B"
}

function Compress-File([string]$path) {
  if (-not $CompressOld) { return }
  try {
    # PS 5.1 用 .NET GZipStream
    $gz = "$path.gz"
    $in = [System.IO.File]::OpenRead($path)
    $out = [System.IO.File]::Create($gz)
    $gzStream = New-Object System.IO.Compression.GZipStream(
      $out, [System.IO.Compression.CompressionMode]::Compress)
    $in.CopyTo($gzStream)
    $gzStream.Close(); $out.Close(); $in.Close()
    Remove-Item $path -Force
  } catch {
    Write-Warning "compress failed: $path - $($_.Exception.Message)"
  }
}

Write-Host "=== logrotate started: $LogDir ==="

Get-ChildItem -LiteralPath $LogDir -File | ForEach-Object {
  $file = $_.FullName
  $size = $_.Length

  if ($size -lt $BytesLimit) { return }

  # 生成轮转文件名：xxx.log.20260603-120000
  $stamp = Get-Date -Format "yyyyMMdd-HHmmss"
  $rotated = "$file.$stamp"

  # 同一秒轮转两次 → 加序号
  $i = 1
  while (Test-Path $rotated) {
    $rotated = "$file.$stamp.$i"
    $i++
  }

  # 移动 + 压缩
  Move-Item -LiteralPath $file -Destination $rotated -Force
  Write-Host "rotated: $(Split-Path $file -Leaf) ($(Format-Size $size)) -> $(Split-Path $rotated -Leaf)"
  Compress-File $rotated
}

# 清理：只保留最近 KeepCount 个轮转文件
Get-ChildItem -LiteralPath $LogDir -File |
  Where-Object { $_.Name -match '\.\d{8}-\d{6}' } |
  Sort-Object LastWriteTime -Descending |
  Select-Object -Skip $KeepCount |
  ForEach-Object {
    Write-Host "pruned: $($_.Name)"
    Remove-Item $_.FullName -Force
  }

Write-Host "=== logrotate done ==="
```

## 注册为每天凌晨 3 点跑

```powershell
$script = "C:\Users\Administrator\.mavis\bin\logrotate.ps1"
$action = New-ScheduledTaskAction -Execute "powershell.exe" `
  -Argument "-NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File `"$script`""

$trigger = New-ScheduledTaskTrigger -Daily -At "03:00"
$principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -RunLevel Highest

Register-ScheduledTask -TaskName "MavisLogRotate" `
  -Action $action -Trigger $trigger -Principal $principal `
  -Description "Rotate mavis logs at 3am daily" -Force | Out-Null
```

或者按需挂 cron（更弹性）：

```bash
mavis cron self logrotate-3am \
  --schedule "0 3 * * *" \
  --prompt "运行 mavis-logrotate.ps1（用 schtasks /Run /TN MavisLogRotate），清理日志"
```

## 手动测试

```powershell
# 1. 造一个大文件
$log = "C:\Users\Administrator\.mavis\logs\test-rotate.log"
$big = "x" * 60MB
[System.IO.File]::WriteAllText($log, $big, [System.Text.UTF8Encoding]::new($false))

# 2. 跑轮转
powershell -NoProfile -File C:\Users\Administrator\.mavis\bin\logrotate.ps1 `
  -LogDir "C:\Users\Administrator\.mavis\logs" `
  -MaxSizeMB 50 -KeepCount 5

# 3. 看结果
Get-ChildItem C:\Users\Administrator\.mavis\logs | Sort-Object LastWriteTime
# 应该看到：test-rotate.log  # 新建的小文件
#           test-rotate.log.20260603-120000.gz  # 压缩后的旧文件
```

## 三种轮转策略

| 策略          | 适合             | 实现                          |
| ----------- | -------------- | --------------------------- |
| **按大小**     | 流量大、日志可能暴涨     | 上面脚本的默认（`MaxSizeMB`）         |
| **按时间**     | 日志规律（每天一行摘要）   | cron 每天 / 每周触发              |
| **混合**      | 生产推荐           | 大小兜底 + 时间清理（脚本 + 计划任务）       |

## 配置矩阵

| 参数          | 建议                | 备注                       |
| ----------- | ----------------- | ------------------------ |
| `MaxSizeMB` | 50                | 太小则轮转频繁，IO 多；太大则单文件难打开    |
| `KeepCount` | 10                | ≈ 10 × 50MB = 500MB 上限     |
| 压缩          | 开                 | gz 比例 5~10x，长期保存必开        |
| 触发频率        | 每天 1 次（时间） + 实时（大小） | 脚本可被多个 cron / 任务触发        |

## 不要轮转的东西

- **当前正在写的日志** —— 脚本用 `Move-Item` 把 inode 让给新文件，进程继续往原 fd 写（Windows 上行为略不同，但大多数进程能自愈）。**不保证** 100% 安全
- **数据库 / 状态文件** —— 用 VACUUM / checkpoint 之类专用机制
- **结构化日志（JSON Lines）** —— 压缩前可以，但轮转策略按"日"而非"大小"，方便按天查

## 进阶：保留期按天数

```powershell
# 在循环末尾加：
$MaxAgeDays = 30
Get-ChildItem -LiteralPath $LogDir -File |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-$MaxAgeDays) } |
  ForEach-Object {
    Write-Host "expired: $($_.Name) (age=$([int]((Get-Date) - $_.LastWriteTime).TotalDays)d)"
    Remove-Item $_.FullName -Force
  }
```

## 故障排查

- 轮转后**进程继续写旧文件** → 重启该进程（大多数日志库不感知文件移动）
- 压缩失败 → 看脚本内 `Compress-File` 异常；多半是文件被占用
- 磁盘还满 → 调小 `KeepCount` 或加 `MaxAgeDays`

## 与 T04 healthcheck 协作

healthcheck 脚本里加一行，定期触发 logrotate：

```powershell
# 在 healthcheck 主循环里，每 6 小时
if (((Get-Date).Hour % 6) -eq 0 -and (Get-Date).Minute -lt 1) {
  & "C:\Users\Administrator\.mavis\bin\logrotate.ps1" `
    -LogDir $LogDir -MaxSizeMB 50 -KeepCount 10
}
```

或干脆用计划任务 3am 跑一次（更干净）。
