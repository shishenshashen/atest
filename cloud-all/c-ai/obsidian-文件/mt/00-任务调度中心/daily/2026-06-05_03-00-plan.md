## §6 04 命名修复 lesson (本巡检新增, 跨项目沉淀)

**问题**: Windows 文件名禁止 `/`, Node.js `writeFileSync(path, content)` 把 `/` 当路径分隔符, 创建"目录 + 子文件"结构, Obsidian [[wiki link]] 解析不匹配。

**示例**:
- 期望文件: `04 经纪商差异(点差/手续费).md` 18,106B
- 实际创建: `04 经纪商差异(点差/手续费).md/手续费).md` (Windows 把 `/` 当路径分隔符)

**根因**:
- Windows 文件系统: 文件名 `04 经纪商差异(点差/手续费).md` → 含 ASCII `/` → 拆成 `04 经纪商差异(点差/手续费).md/` (目录) + `手续费).md` (子文件)
- Linux/Mac 文件系统: 文件名合法, 创建成功
- mavis-trash 假成功 (返回 ok 但目录还在, Windows mavis-trash 对子目录有 bug)
- 改用 Node.js `fs.rmSync(path, { recursive: true, force: true })` 硬删 (已留备份到 plan workspace)

**修复**:
1. mavis-trash 删 2 旧目录 (假成功, 实际未删)
2. Node.js fs.rmSync 硬删 2 旧目录
3. Write 工具新建 `04 经纪商差异-点差-手续费.md` 18,106B (用 `-` 替代 `/`)
4. 跨全库 grep 替换链向 `[[04-避坑与速查/04 经纪商差异(点差/手续费)|...]]` → `[[04-避坑与速查/04 经纪商差异-点差-手续费|...]]` (17 wiki 56 处)

**预防** (写 wiki 必避):
- 写 wiki 文件名用 `-` 替代 `/` (例: `04 经纪商差异-点差-手续费.md` 而非 `04 经纪商差异(点差/手续费).md`)
- 用全角 `（）` 替代半角 `()` (例: `04 经纪商差异（点差、手续费）.md`)
- 写完 wiki 后 Node.js fs.statSync 验证文件存在 + 字节符合预期 (不只看 mtime, stat 验证)

**写 memory entry** (T1 owner 03:00 收尾时):

- Topic: `powershell-windows.md` 或新 `windows-filename.md`
- Content: Windows 文件名禁止 `/` / `:` / `*` / `?` / `"` / `<` / `>` / `|`, Node.js writeFileSync 把 `/` 当路径分隔符, 创建"目录 + 子文件"结构; mavis-trash 假成功, 改用 fs.rmSync 硬删
