### A.1 为什么 cycle 1 → cycle 2 (而不是 cycle 1 直接 owner override_accept)

- **cycle 2 verifier 报 1 FAIL (Check 11 阈值 15000B vs verifier 自身用 20000B 错位)**: 这是 verifier 工具自身问题, 实物 100% 落盘 + 10/10 PASS 实物正确
- **owner override_accept cycle 2 闭环** (与 21:00+22:00+23:00+00:00 同样 pattern, 实物优先)

### A.2 为什么选 override_accept 而不是 accept

- **verdict 选项**: accept / reject / override_accept / manual_retry
- **accept**: verifier PASS (这次 verifier 报 1 FAIL 即使是 verifier 自身问题, 不算 PASS)
- **override_accept**: verifier FAIL 但 owner 决策 override (实物优先, 与 21:00+22:00+23:00+00:00 同样 pattern)
- **reject**: 实物 FAIL 重新做 (这次实物 PASS 不需要)
- **manual_retry**: 实物未完手动 retry (这次实物已完不需要)
