## 三、关键反模式要点 (5 速查 31 条总览)

### 01 编译 (6 条)
1. `extern` 误写 → EA 输入面板"消失"（MQL5 已废弃 extern）
2. 跨文件 `const` 传参 → 编译过运行期崩
3. 全局对象声明顺序错 → OnInit 抛 NULL
4. OnInit 失败路径 `return 0` 而非 `INIT_FAILED`
5. input 默认值 = 0 → EA "不动"（除零 / 不开仓）
6. Print 每 tick 调 → 回测 10x 慢

### 02 OrderSend (6 条)
1. 忽视 `TRADE_RETCODE_DONE` 之外的 retcode
2. 不设 `deviation` → 99% 拒单（deviation=0 太严）
3. 同一 magic 多窗口 / 不同 magic 同方向 → M07.HasDirection 错位
4. SL/TP 价格没 `NormalizeDouble` → INVALID_STOPS
5. 用裸 `OrderSend` 替代 M01 CTradePlus
6. 不监听 `OnTradeTransaction` 拒单

### 03 实盘 vs 回测 (6 条)
1. 回测用 `last_month` 默认 1 个月就下结论
2. 回测用"每个 tick 基于真实 tick" 当默认（慢）
3. 不看 `OnTester` 结果直接用回测最优参数
4. 回测最优参数直接上实盘（100% 过拟合）
5. 假设 24h 流动性恒定（凌晨 3-5 点是地雷）
6. 不区分 demo / 实盘的 server timezone

### 04 经纪商 (6 条)
1. 硬编码 5 位小数 → 跨经纪商 INVALID_STOPS
2. 用 `MarketInfo(_Symbol, MODE_SPREAD)`（MQL5 已废弃）
3. 假设所有经纪商支持 FOK（实际只有 ECN）
4. 跨经纪商 EA 不测 swap / commission
5. 假设 1 标准手 = 100,000（XAUUSDm 100 oz, BTC 1 BTC）
6. 不读 `ENUM_ACCOUNT_MARGIN_MODE`（netting vs exchange）

### 05 必查清单 (7 条"永远不要")
1. 永远不要忘了 `OnDeinit` 清理资源（GV / Cleanup / EventKillTimer / FileClose）
2. 永远不要把 SLTP 算进 PnL 但不考虑 commission
3. 永远不要忘了给 EA 写 `#property description`
4. 永远不要直接调 `SymbolInfoTick` 不用 `CopyTicks` (5+ 倍延迟)
5. 永远不要在 `OnTick` 调 `FileOpen` (高频 IO 阻塞)
6. 永远不要假设 `PositionsTotal() == 0` 等于"无持仓"（必用 CPositions::CountMine(Magic)）
7. 永远不要跳过 `deviation` 容忍度（市价单全被拒）

**6 个永远不要 (核心警示)**:
1. 永远不要全仓跑（资金 ≥ 10x 单边最大亏损, 不是 30%）
2. 永远不要在新闻 / 非农 / CPI 前运行（M17 必须接）
3. 永远不要假设"均价止盈"一定能打回（单边市 800-2000 点）
4. 永远不要在单品种上跑（多品种对冲也救不了）
5. 永远不要把马丁逻辑套到剥头皮 / 高频（commission 吃光）
6. 永远不要在回测"赚钱"后就上实盘（5 年区间必有 1-2 灾难月）

**5 已知陷阱**: 等比 r=2 第 5 层 16x 首单 / GridStep 太小 commission 吃光 / 斐波 6 层后 8x 首单 / 新闻瞬间连开 3-5 单 / 周末跳空

**5 替代方案**: 顺势 MA 交叉 / 逆势 BB+RSI / 多品种对冲 M18 / 时段过滤 M19 / 仓位管理 M02+M03 (各链向实物 demo)

**8 步回测 SOP**: 5 年数据 / 1 分钟 OHLC / 10K USD / 2 套参数 / 4 指标 / 最差月 / Walk-Forward / 黑天鹅压力测试

**5 个绝对不能用的回测结论**:
- ❌ "1 年回测 Net Profit +200%" — 看 5 年
- ❌ "Max DD < 10%" — 多半 trade count < 30
- ❌ "Sharpe > 2.0" — 马丁天然 Sharpe 高, Max DD 也高
- ❌ "Profit Factor > 3.0" — 等比马丁天然 PF 高, 单边市破功
- ❌ "1 个月 demo 不爆 = 安全" — 马丁平均 14 个月才爆
