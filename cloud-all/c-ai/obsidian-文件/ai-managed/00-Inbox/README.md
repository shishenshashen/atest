# 📥 00-Inbox · 老大剪藏入口

> **本目录是 AI（小神龙）的工作起点。**
> 老大把外源材料（教程/文章/代码/视频脚本/参考文档）丢到这里，AI 读取、消化、归档到 vault 其他位置。

## 🎯 老大您只做一件事

**把材料丢进来**：
- 整段文章 → 直接保存为 `.md` 文件
- 链接 + 几句话摘要 → 命名为 `YYYY-MM-DD_<主题>.md`
- 视频脚本/采访 → 转文字后保存
- 任何您觉得"以后可能用得上"的东西

**文件命名建议**（不强求）：
- `2026-06-10_MT5内存管理技巧.md`
- `2026-06-11_某教程笔记.md`

## 🤖 AI 做什么

AI 每次会话开始时会扫这个目录，发现新文件就处理：

1. **读取** → 理解内容
2. **提炼** → 抽取 1-3 段核心要点
3. **分类** → 决定归档到哪（`10-提炼/`、`20-经验沉淀/`、`30-技能档案/`、`40-项目档案/`）
4. **写入** → 写新文件到对应分类
5. **建立链向** → 在相关旧文件加 wikilink
6. **更新 MOC** → 在 `90-索引/MOC.md` 加条目
7. **移动原文件** → 完成后原文件移到 `98-已处理/`

## 📋 归档目标速查

| 内容类型 | 归档到 |
|---------|--------|
| 教程/技术文章/工具介绍 | `10-提炼/<主题>/` |
| 老大做的项目经验/决策 | `20-经验沉淀/YYYY-MM/` |
| 新学的技能/CLI/API | `30-技能档案/` |
| 项目文档/代码参考 | `40-项目档案/` |

## ⚠️ 重要规则

- ❌ **AI 不动** `mt/` vault（只读）
- ❌ **AI 不覆盖** `ai-managed/` 下任何手写文件（只追加/新建）
- ❌ **AI 不删** 任何文件（归档后移动到 `98-已处理/`，老大可清空）
- ✅ **AI 主动** 维护 `90-索引/MOC.md`
- ✅ **AI 主动** 加 wikilink
