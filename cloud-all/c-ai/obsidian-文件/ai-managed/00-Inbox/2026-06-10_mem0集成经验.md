# 今日成果：mem0 外置记忆库集成

来源：今天（2026-06-10）和小神龙的对话

## 背景
Hermes 内置 MEMORY.md/USER.md 只有 2200 字符上限。老大需要更大的记忆容量。

## 过程
1. 装了 mem0 reference skill（5 个里选了 mem0）
2. 老大提供了 mem0 官网的 API key
3. 配置 `hermes config set memory.provider mem0` + 写 .env
4. 验证 ping ok
5. 写了 1 条测试记忆 + 4 类事实共 16 条
6. 验证语义搜索 4/4 通过

## 关键发现
- mem0 自动做 fact extraction（不需要 LLM 配）
- 自动结构化时间戳（day_of_week、week_of_year 等）
- 内置语义搜索 + reranking
- API 走 api.mem0.ai（境外源）

## 教训
- ghp_*/sk-* 字面量被 Hermes 重写为 ***，要 chr() 拼接
- 写 PowerShell 别用 bash 内联（$_ 被吞）
